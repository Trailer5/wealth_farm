## 一、阶段定位

本阶段对应长期路线图“目标能力体系”中第三层的补全，以及第二层的决策结算闭环。

当前单标的研究已能发布回答是否、何时、多少的最终决策报告，但存在三个缺口：

1. 报告发布后，系统不知道这些判断事后是否正确。
2. 已持有标的缺少结构化的卖出、减持和换仓计划。
3. 估值只能回答历史和同行分位，不能回答当前价格隐含了什么预期。

本阶段目标：

1. 每份最终决策报告发布时冻结一组可结算决策，包括买入、等待、回避、持有、减持和退出。
2. 到期后按统一规则前向结算，对照基准和同风险替代方案。
3. 已持有标的有独立的持有复核与退出计划，每项动作都有可观察条件和有效窗口。
4. 普通公司和金融机构可以输出内在价值区间和市场隐含预期。
5. 结算结果经结构化复盘形成校准摘要，说明哪些判断类型可信、哪些尚不可判。

本阶段同时冻结“可结算动作”格式，作为后续全市场发现和组合行动日历的共同接口。

## 二、用户能得到什么

1. 每个结论的成绩单：当初说了什么、条件是否兑现、到期后相对基准和替代方案表现如何。
2. 已持有标的的卖出指导：继续持有、分批止盈、减持、退出或换仓，以及各自的触发条件。
3. 估值回答“当前价格要求公司做到什么”和“乐观、基准、悲观情景下的价值区间”。
4. 定期复盘：哪类结论更可靠；样本不足时明确说明还不能判断。

## 三、当前基线

### 已有

1. `final_decision_publications` 保存最终报告发布证明；`MonitoringHandoffService` 可在用户确认后把价格、事件、日期和组合权重条件注册为提醒规则。
2. 是否轨道已有 `SuitabilityAction.HOLD_REVIEW`，决策意图已有 `DecisionIntent.REVIEW_HOLDING`，仓位轨道已有 `PositionAction.REDUCE`。
3. 时点轨道 `EntryPlan` 的维度只覆盖进入侧：当前状态、进入、等待、分批、回避、催化窗口、失效、可交易时间、执行约束和跨周期冲突。
4. `fundamental_analysis` 已有 PE、PB、PS、PCF、EV 倍数、ROE、ROIC 和自由现金流；`market_analysis` 已有指数股权风险溢价；数据源已有 10 年国债收益率。
5. `src/state_capital_flow/calibration.py` 只校准国家队周级代理方向，不是通用决策结算。
6. 低频回测只覆盖确定性规则；Agent 判断无法用历史回放无偏验证。

### 缺口

1. 发布的结论没有冻结为可结算记录，等待和回避结论也没有被追踪。
2. 没有前向结算、复盘和校准。
3. 没有退出侧时点计划；最终报告第 9 章“失效、退出与复查”只能依赖失效条件。
4. 没有 DCF、反向 DCF 或 PB-ROE 隐含预期。

## 四、设计原则

1. **发布即冻结**：结算对象是发布时冻结的结构化决策，不是报告正文；发布后不得修改或删除，只能追加结算和复盘。
2. **全部入账**：买入、等待、回避、持有、减持和退出全部入账；不允许只记录看起来正确的结论。
3. **前向计价**：参考价使用发布后第一个可成交价格。场内标的取下一交易日收盘；场外基金按申赎确认规则取确认净值。不使用发布前价格。
4. **结果与质量分离**：价格结果回答“赚没赚”，论文假设兑现情况回答“判断过程对不对”，两者分开记录。
5. **不设通用样本门槛**：校准输出区间和样本量；区间过宽时明确为不可判，不用固定样本数宣称有效。
6. **Agent 历史回放不计入校准**：模型训练数据可能覆盖回放期，Agent 判断只用真实前向决策校准；确定性规则仍可用历史回测。
7. **退出与进入对称**：已持有标的发布“继续持有”时必须同时给出退出条件。
8. **区间优于点值**：DCF 只输出情景区间和敏感性，反向 DCF 是主产物；不输出目标价。
9. **不下单**：只输出可验证的条件和动作，不生成订单。

## 六、目标契约

### 1. 可结算决策

最终报告发布时，从三个决策对象、退出计划和监测计划中投影出若干条记录：

```text
SettleableDecision
  decision_id
  publication_id / workflow_run_id / user_id / asset_id / profile_id
  decision_lane          # suitability | timing | position | exit
  action                 # 各轨道已有动作枚举的映射
  as_of_date / published_at
  reference_price_rule
  checkpoints            # 按时间尺度生成的结算日序列
  benchmark_asset_id
  alternative_asset_id   # 是否轨道已记录的同风险替代方案，可空
  thesis_assumptions     # 每项带可观察键和预期状态
  invalidation_refs      # 指向已发布的失效条件
  stated_probability     # 可选；只接受发布前显式记录的概率
  content_digest
```

不复制报告正文，不保存用户组合数值，只引用已有 ID。

### 2. 结算

```text
DecisionSettlement
  decision_id / checkpoint_date
  status                 # settled | pending | data_insufficient | not_settleable
  entry_reference / checkpoint_value / price_evidence
  absolute_return / benchmark_return / excess_return / alternative_return
  max_adverse_excursion / max_favorable_excursion
  triggered_conditions
  assumption_states      # met | missed | unknown
```

等待和回避结论同样结算：记录等待期内标的相对基准的表现，以及等待条件是否出现。

### 3. 复盘

结算后由 Agent 追加结构化复盘：

1. 哪些论文假设兑现，哪些落空。
2. 结果主要来自论文、市场 Beta 还是运气。
3. 过程分类：判断对且理由对、判断对但理由错、判断错但过程合理、过程有缺陷。
4. 可执行的教训。

复盘只追加，不修改结算和原始决策。

### 4. 校准摘要

按结论类型、profile、时间尺度和引用策略分组，输出样本量、相对基准命中率区间、超额收益分布；有发布前概率时输出 Brier 分数。区间过宽时标为不可判。

### 5. 退出计划

适用于已持有或持仓复核意图，通过容器中新增的退出计划入口装配：

- 维度：论文关键指标检查、估值透支（当前价格隐含预期超过乐观情景）、分批止盈、风险预算超限、更优替代（同风险替代方案的机会成本）、时间止损（催化窗口过期）、论文失效。
- 状态：hold、trim、exit、switch、insufficient。
- 每项带可观察键、有效窗口和证据引用；与进入计划冲突时显式保留，不取平均。
- 渲染进最终报告第 9 章“失效、退出与复查”，不新增章节。

### 6. 内在价值与隐含预期

1. 普通公司：两阶段自由现金流折现。输入为 TTM 自由现金流、分阶段增长、永续增长、折现率（10 年国债收益率加股权风险溢价假设）和净负债；输出三情景区间与敏感性表。
2. 反向 DCF：在当前市值下求解隐含增长率或隐含高增长年数，并与自身历史和同行对照。
3. 金融机构：使用 $P/B = \frac{ROE - g}{r - g}$，反解当前 PB 隐含的可持续 ROE。
4. 周期资源、ETF 和场外基金：本阶段正式返回不支持。
5. 所有输入带来源、报告期和发布日期；结果作为是否轨道“定价预期”维度的证据输入。

#### 实施步骤
