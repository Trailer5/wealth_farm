# Wealth Farm 长期发展路线图

## 定位

Wealth Farm 首先是投研系统，其次才是数据平台、Web 产品或 AI 应用。

当前第一阶段的目标是：

> 在 IDE 环境中选择一个标的，使用项目已有工具完成身份确认、数据获取、指标和图表、行业与市场比较、策略分析、反证和研究报告。

只要这条研究路径没有完成，数据库抽象、daily_data 自动化、前端展示、用户身份、提醒和 AI harness 都只能作为支撑能力，不能成为阶段主线。

## 核心成果

第一阶段完成时，用户应能在 IDE 中提出类似任务：

1. 全面研究贵州茅台的中长期投资价值。
2. 判断黄金 ETF 在未来 1 至 6 个月是否存在投机机会。
3. 比较沪深 300 ETF 与市场、同类指数和自身历史风险收益。
4. 判断某只周期股当前处于什么产业和估值阶段。
5. 从某个行业或全市场发现值得进一步研究的候选标的。

项目应输出可复核的研究结果，而不是只返回数据或一段自然语言。

## 当前基线

### 已经较强

1. 股票、ETF 和基金的标的身份标准化、稳定 `asset_id` 和来源代码映射。
2. 股票与 ETF 多源日线、场内基金实时数据和场外基金净值。
3. A 股三大报表、财务指标和披露计划获取入口。
4. CNINFO、交易所、基金披露、监管信息和研报元数据。
5. PDF 下载、文本、表格、OCR 和财务字段抽取基础。
6. 统一数据访问、质量检查和 Provider 超时/fallback。

### 只有基础能力

1. `return_1d`、`sma_5`、`momentum_5`、`volatility_5` 和 `drawdown` 五个行情因子。
2. Web 中的基础 OHLC/成交量图。
3. 公告标题事件规则。
4. 当前持仓估值和集中度。

### 当前主要缺口

1. PE、PB、EV、FCF Yield、ROE、ROIC、利润率、成长和资产负债指标。
2. Sharpe、Sortino、Calmar、Beta、Alpha、信息比率和完整回撤分析。
3. IDE 可复用图表。
4. 行业、市场、指数、宏观和可比公司数据与比较。
5. 策略对象、复合判断、时间尺度和可信回测。
6. 标的发现。
7. 统一的 IDE 单标的研究任务和 `.agent` 研究指引。

这些缺口是当前主要矛盾。

## 当前阶段边界

### 当前必须推进

1. 研究数据契约和资产类型模板。
2. 因子、指标和图表。
3. 行业、市场、基准和同行比较。
4. 策略、时间尺度和低频回测。
5. 标的发现。
6. 代表性标的端到端研究。
7. IDE Agent 研究流程。

### 当前保持维护，不主动扩展

## 一、标的身份标准化

主数据模块必须统一：

1. 股票、ETF、LOF、场外基金、指数和行业。
2. 公司、基金公司、基金经理和发行主体。
3. 市场、交易所、代码、名称、简称和历史名称。
4. 外部 Provider 代码。
5. 指数、行业、底层资产和可比关系。

当前证券与基金身份基础较完整。下一步只补研究必需关系，例如：

1. 公司与行业。
2. ETF 与底层指数。
3. 基金与管理人。
4. 公司与主要竞争对手。
5. 资源公司与主要商品。

不得为了构建全量知识图谱延误研究。

## 二、研究数据获取

单标的研究至少需要以下数据层：

### 行情与交易

1. 复权日线、成交量、成交额和换手率。
2. 指数和基准行情。
3. 公司行为、分红、拆股、停牌和复权因子。
4. 必要时的实时或分钟数据，但不作为第一阶段默认要求。

### 财务与报表

1. 资产负债表、利润表和现金流量表。
2. 单季、累计、年度和滚动口径。
3. 股本、市值、净现金、有息负债和企业价值。
4. 财务指标、报告期、币种和单位。
5. 原始财报和关键字段证据。

### 公司、基金与事件

1. 官方公告和财报。
2. 回购、分红、增减持、管理层和监管事件。
3. 基金净值、规模、费率、申赎和持仓披露。
4. 研报元数据和必要原文。
5. 新闻和事件信息；当前通用新闻 Provider 仍缺失。

### 比较与环境

1. 行业、产业链和可比公司。
2. 宽基、行业、风格和底层指数。
3. 市场估值、成交、宽度和风险偏好。
4. 利率、汇率、通胀、信用和大宗商品。

数据获取的验收不是“接口存在”，而是能为研究问题提供可追溯、单位明确、截止日期明确的数据。

## 三、基础参数、因子和图表

### 价格和风险

1. 单期与累计收益。
2. 波动率、下行波动率和最大回撤。
3. Sharpe、Sortino 和 Calmar。
4. Beta、Alpha、相关性和信息比率。
5. 相对强弱、趋势、动量、均线和量价。

### 估值

1. PE、PB、PS、PCF。
2. EV/EBITDA、EV/FCF。
3. Earnings Yield、FCF Yield 和股息率。
4. 估值历史分位和同行分位。
5. 乐观、中性和悲观情景估值。

### 财务质量与成长

1. ROE、ROA 和 ROIC。
2. 毛利率、营业利润率和净利率。
3. 收入、利润、经营现金流和自由现金流增长。
4. 现金含量、应收、存货、资本开支和营运资本。
5. 杠杆、利息保障、偿债和流动性。
6. 分红、回购、稀释和资本配置。

### ETF 和基金

1. 净值收益和折溢价。
2. 跟踪误差和信息比率。
3. 规模、费率、流动性和申赎。
4. 底层指数估值、行业和持仓暴露。

不得给所有资产套用同一指标模板。

### 必要图表

1. 复权 K 线、成交量和均线。
2. 累计收益与基准。
3. 回撤和修复周期。
4. 滚动波动率、Sharpe、Beta 和相关性。
5. 估值区间和历史分位。
6. 收入、利润、现金流、利润率、ROE 和 ROIC 趋势。
7. 同行关键指标对比。
8. 风险—收益散点。
9. 财报、公告和重要事件叠加。

图表必须同时保留可复算数据、数据截止日期、来源、单位、复权方式、窗口和基准。

## 四、行业、市场和整体比较

单标的研究必须回答：

1. 它相对自身历史发生了什么变化。
2. 它相对同行更好还是更差。
3. 变化来自公司自身、行业景气还是市场 Beta。
4. 当前价格已经反映了什么预期。
5. 主要竞争者、替代品和产业链瓶颈是什么。
6. 标的对利率、汇率、商品和政策有何敏感性。

比较至少覆盖：

1. 3 至 10 个合理可比对象。
2. 一个主基准和必要的行业基准。
3. 估值、质量、成长、风险和相对收益。
4. 行业供需、竞争格局、利润池和周期位置。

比较必须统一币种、单位、报告期和会计口径，并防止历史成分和幸存者偏差。

## 五、具体策略与复合判断

策略必须是可运行、可解释、可回测的研究规则。

首批策略类别：

1. 技术与择时。
2. 估值与均值回归。
3. 质量与成长。
4. 景气与周期。
5. 事件和催化剂。
6. 行业轮动和相对强弱。
7. 基本面价值投资。
8. 多指标复合。
9. 投资论文跟踪和漂移。
10. 标的发现。

复合策略支持：

1. AND/OR 条件。
2. 硬门槛和一票否决。
3. 加权评分。
4. 分层漏斗。
5. 多情景。
6. 不同时间尺度的冲突处理。

策略必须记录适用资产、时间尺度、输入、参数、版本、有效期、失效条件、反证和回测状态。

## 六、时间尺度

### 短期：不超过 1 个月

负责择时。重点使用价格、成交、波动、事件、流动性、相对强弱和市场风险状态。

短期信号只能回答“现在是否适合行动”，不能回答“企业是否值得长期持有”。

### 中短期：大于 1 个月且不超过 6 个月

负责投机性机会。重点使用催化剂、业绩预期差、估值修复、行业景气、中期趋势和风险收益比。

必须声明催化剂兑现窗口、失败条件和损失边界。

### 中长期：大于 6 个月且不超过 3 年

负责投资。重点使用盈利、现金流、ROIC、竞争格局、管理层执行、合理估值和安全边际。

### 长期：大于 3 年

负责阅读和穿越周期。重点使用商业模式、护城河、资本配置、治理、结构趋势、周期位置、机会成本和永久性资本损失。

每个指标和策略必须声明适用时间尺度。不得把短期异动、长期好公司和当前买点混成同一结论。

## 七、标的发现

标的发现不局限于用户自选。系统需要在以下时机主动形成候选：

1. 市场和行业大幅回撤。
2. 估值进入历史或同行极端。
3. 盈利、现金流、景气或竞争格局出现拐点。
4. 重大事件造成价格与基本面脱节。
5. 高质量标的进入合理价格。
6. 产业链出现真实瓶颈或利润池迁移。
7. 相对强弱、量价或风险状态异常。

发现流程：

1. 定义研究宇宙。
2. 执行硬性排除。
3. 保存初筛候选和命中原因。
4. 使用行业、基准和同行复筛。
5. 保存淘汰理由和数据缺口。
6. 把少量候选送入完整单标的研究。

发现结果只是研究邀请，不是交易建议。

## 八、IDE Agent 研究路径

底层能力稳定后，`.agent` 应形成以下研究路径：

1. 识别标的、资产类型、问题和时间尺度。
2. 确认 `asset_id` 和 Provider 代码。
3. 生成数据需求清单。
4. 获取并质量检查数据。
5. 计算适用指标和图表。
6. 完成行业、市场、基准和同行比较。
7. 运行与时间尺度匹配的策略。
8. 生成乐观、中性、悲观情景。
9. 进行反向检验、反共识检查和论文证伪。
10. 区分事实、推断、假设和未知。
11. 输出研究报告、证据、图表、数据缺口和下一步。

完整 Agent 指引只能在底层研究能力和输出契约稳定后编写，不能先用 prompt 掩盖功能缺失。

## 九、研究质量与决策纪律

除用户提出的八项重点外，当前阶段还必须补充：

### 研究问题

每次研究先说明是理解、择时、投机、投资、论文复查、风险排查还是候选发现。不同问题不能共享同一默认结论。

### 数据截止与证据

报告顶部声明截止日期。关键数据优先使用官方来源，并至少使用两个独立来源或独立算法核验。

### 资产类型模板

普通公司、金融机构、周期资源、高成长未盈利公司、ETF 和基金必须使用不同模板。

### 精确计算

市值、估值、币种、单位和股本使用精确十进制和独立复核。LLM 不负责关键金融算术。

### 反证和留白

输出最强反方观点、论文失效条件和未知项。资料少不等于标的差，资料多也不等于确定性高。

### 回测纪律

策略必须处理未来数据、复权、停牌、成本、滑点、成分变化、样本外验证、过拟合和幸存者偏差。

### 论文生命周期

研究结论应形成可证伪论文。后续复查区分事实变化、估值变化、市场情绪和措辞变化。

### 校准

长期应记录策略信号、置信度和后续结果，用真实结果校准哪些策略、指标和 Agent 判断有效。

## 十、外部参考使用

`references/ai-berkshire` 属于策略思想参考，不是 Wealth Farm 的运行依赖。

适合吸收：

1. 商业模式、财务估值、行业竞争、风险和管理层的多视角对抗。
2. 能力圈、好生意、护城河、管理层、安全边际和纪律检查。
3. 三情景估值、反向思考和快速否决。
4. 信息丰富度与结论置信度分离。
5. 财务数据双来源和精确计算。
6. 行业漏斗、质量筛选和瓶颈发现。
7. 投资论文跟踪和漂移。
8. 新闻异动的价值事件与情绪区分。

不直接照搬：

1. 评分权重和阈值。
2. 收益记录和具体投资结论。
3. 大师姓名包装的权威结论。
4. 未经本项目数据验证的价格和仓位。
5. 外部代码、目录和联网依赖。

## 十一、支撑层定位

### 数据库与持久化

只负责让研究输入和结果可读取、可复算。当前不继续抽象 schema，除非新指标、策略或报告明确需要。

### daily_data

当前暂停。新闻和自动跟踪属于后续能力，不阻塞 IDE 单标的研究。日线按需进入 SQLite。

### Web

当前工作台保留，不继续扩展。IDE 研究能力成熟后，再选择值得展示和交互的研究产物。

### 用户空间

保留当前轻量隔离，不建设登录、权限或多租户。

### AI harness

保留任务、证据和 Adapter。当前阶段优先把可靠研究工具交给 IDE Agent，不继续建设产品内 AI 体验。

## 项目阶段

### 阶段 0：身份与数据基础

目标是正确识别标的并获取研究所需数据。

当前状态：基础能力较完整，按研究缺口维护。

### 阶段 1：IDE 单标的研究核心

目标是完成统一研究数据面、指标、图表、资产模板和标准研究输出。

主要交付：

1. 财务、公告、研报、场外基金和文档字段的统一访问。
2. 报告期、TTM、币种、单位、修订和数据截止契约。
3. 估值、财务质量、成长和风险调整后指标。
4. 可复用 IDE 图表。
5. 数据截止、证据、反证和研究报告契约。
6. 股票、金融机构、周期标的、ETF 和基金模板。

当前阶段正在推进。

### 阶段 2：比较、策略与回测

目标是把标的放入行业和市场，并形成与时间尺度匹配的可验证策略。

主要交付：

1. 同行、行业、指数、市场和宏观比较。
2. 策略对象和复合判断。
3. 四类时间尺度。
4. 可信低频回测。
5. 投资论文和漂移检测。

### 阶段 3：标的发现与 Agent 研究

目标是从更大研究宇宙发现候选，并让 Agent 执行完整 IDE 研究路径。

主要交付：

1. 研究宇宙和候选漏斗。
2. 质量、估值、成长、周期、事件和技术发现策略。
3. 代表性资产端到端验证。
4. `.agent` 研究路由、执行手册、报告和复查规范。

### 阶段 4：持续信息、产品和运维

只有前三阶段稳定后再评估：

1. daily_data 新闻与信息增量。
2. Web 产品深化。
3. AI harness 产品化。
4. 用户认证、多租户和部署。
5. 外部通知和长期自动运行。
