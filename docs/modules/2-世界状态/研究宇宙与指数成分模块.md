# 研究宇宙与指数成分模块

## 模块职责

本模块把外部指数成分快照转换为可查询、可追溯的候选标的集合。它保存研究宇宙 ID、来源、版本、获取时间、有效日期、稳定 `asset_id`、未解析成员和质量摘要。

研究宇宙只描述候选集合，不表达策略判断或买卖结论。

## 目录范围

1. `src/research_universe/`：拥有 universe 模型、导入服务、安全查询和 SQLite repository。
2. `src/tests/research_universe/unit_tests/`：覆盖幂等导入、重复成员、未解析身份和历史误用拒绝。
3. `src/tests/research_universe/smoke_tests/`：覆盖沪深 300 真实当前成分获取、身份解析和持久化。
4. `src/data_src/akshare/provider.py`：有限覆盖中证指数当前成分底层获取。
5. `src/master_data/`：依赖；负责把来源代码解析为稳定资产身份，并保存待复核观察。

## 当前模型

1. `ResearchUniverse`：记录 universe ID、名称、关联指数、来源、版本、获取时间、有效日期和历史成员能力。
2. `UniverseMembership`：记录来源代码、名称、交易所、`asset_id`、状态和未解析原因。
3. `UniverseQualitySummary`：记录来源记录数、唯一代码数、已解析、未解析、非活跃和重复数量。
4. `UniverseSnapshot`：组合一个版本及其成员和质量摘要。

SQLite schema version 21 使用 `(universe_id, version)` 保存版本，并使用 `(universe_id, universe_version, source_symbol)` 保证同版本重复导入不产生重复成员。

## 数据源与版本

首个数据源为 AkShare `index_stock_cons_csindex`，底层返回中证指数成分快照。项目把来源精确记录为 `akshare:index_stock_cons_csindex`。

版本由来源有效日期和来源名称确定，例如 `2026-07-31:akshare-index_stock_cons_csindex`。一个快照只接受一个来源和一个有效日期，避免把不同口径静默合并。

## 安全边界

1. 当前成分快照的 `historical_membership` 固定为 `false`。
2. 历史回测请求当前快照时，`ResearchUniverseService.members(..., for_historical_backtest=True)` 明确抛出 `HistoricalUniverseUsageError`。
3. 当前成分不得回填成历史成分，也不得用于无偏历史选股。
4. 非六位成分代码不自动创建资产；它会以 `unresolved` 状态保留，并进入主数据待复核观察。
5. 重复来源代码不重复保存，但必须计入质量摘要。

## 当前能力

2026-08-03 真实 smoke 获取沪深 300 有效日期 `2026-07-31` 的 300 条当前成分：300 个唯一代码、300 个稳定身份、0 个未解析、0 个重复。smoke 使用临时 SQLite，不污染正式数据。

当前只实现当前成分，不实现历史成分、全 A 股、行业成分、自动更新或筛选策略。

## 使用方式

运行单元测试：

```powershell
python -m unittest src.tests.research_universe.unit_tests.test_research_universe
```

运行真实 smoke：

```powershell
python src/tests/research_universe/smoke_tests/run_csi300_universe_smoke.py
```
