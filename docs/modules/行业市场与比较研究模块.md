# 行业、市场与比较研究模块

## 模块职责

本模块负责把单标的放回行业、产业链、市场和宏观环境中研究。任何标的结论都应回答“相对谁更好、处于什么周期、市场已经定价了什么”。

## 比较层级

1. 标的自身历史：价格、估值、盈利、现金流和风险历史。
2. 直接可比公司：同业务、同客户、同地区或同商业模式。
3. 行业与产业链：上游、核心环节、下游、替代品和潜在进入者。
4. 基准指数：宽基、行业指数、风格指数和底层指数。
5. 市场整体：估值、风险偏好、波动、流动性和市场宽度。
6. 宏观与跨资产：利率、汇率、通胀、信用、大宗商品和政策。

## 数据能力

需要逐步补齐：

1. 行业和主题分类。
2. 指数、成分和历史成分。
3. 同行财务与估值数据。
4. 行业产量、价格、库存、产能和渗透率。
5. 市场指数、成交、宽度、风格和风险状态。
6. 利率、汇率、商品和宏观指标。
7. 产业链关系和主要竞争对手。

主数据模块负责实体和关系身份，本模块负责比较集合、比较口径和研究输出。

## 比较纪律

1. 比较对象必须解释为什么可比。
2. 币种、会计准则、报告期和一次性项目必须统一。
3. 周期位置不同的公司不得直接比较单期估值。
4. 银行、保险、资源、制造、互联网、基金和 ETF 使用不同指标模板。
5. 行业平均值必须同时给出样本数量、中位数和离散程度。
6. 当前成分不得回填到历史时期造成幸存者偏差。
7. 结论必须区分绝对改善与仅仅随行业上涨。

## 必要输出

1. 标的与 3 至 10 个可比对象的关键指标对比。
2. 相对行业和基准的收益、波动和回撤。
3. 行业景气、供需、竞争格局和利润池变化。
4. 市场风险状态和主要宏观敏感因素。
5. 标的优势、劣势、差异化和市场预期。
6. 对当前研究时间尺度的影响。

## 与参考策略的关系

可以借鉴 `references/ai-berkshire` 的产业链全景、行业漏斗、质量筛选和瓶颈发现思想：

1. 先验证需求和价值链逻辑，再找公司。
2. 按产业链环节研究利润池和不可替代性。
3. 粗筛保留淘汰理由，避免黑箱。
4. 终选考虑确定性、弹性和风险的互补，而不是只按总分排序。
5. 瓶颈真实不等于投资机会，估值和盈利仍是硬门槛。

## 当前能力与缺口

当前数据获取层有部分行业、基金配置和指数相关入口，但尚未形成统一行业主数据、历史成分、同行集合、市场状态和比较服务。

该模块是单标的全面研究的必要组成，应在基础指标之后立即建设，而不是等到 Web 或组合产品阶段。
