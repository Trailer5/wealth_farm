# 研究可视化模块

## 模块职责

本模块负责把行情、风险、估值和财务序列转换为 IDE 可读取的静态研究图表，并同时保存同源数据和 metadata。

## 目录范围

1. `src/research_visualization/`：图表模型、builder 和 Matplotlib renderer。
2. `src/tests/research_visualization/unit_tests/`：产物、截止日期和字段测试。
3. `src/tests/research_visualization/smoke_tests/`：真实研究图表验证。

## 当前图表类型

1. `price_volume`
2. `cumulative_return`
3. `drawdown`
4. `rolling_risk`
5. `valuation_history`
6. `financial_trends`

## 产物契约

每张图生成：

1. PNG。
2. SVG。
3. 同源 `.data.json`。
4. `.metadata.json`。

metadata 包含任务、标的、截止日期、单位、币种、复权方式、基准、来源 dataset、参数、版本、点数和输入摘要哈希。

## 输出边界

默认写入：

```text
temp/research/<task_id>/charts/
```

`temp/` 已被 Git 忽略。正式报告只引用显式选择的产物。

## 当前能力

1. 六类图表均可通过 Python API 生成。
2. 相同 `ChartSpec` 产生相同文件名和 metadata。
3. 图表数据严格过滤到 `as_of_date`。
4. PNG、SVG 和 JSON 使用同一数据对象。
5. 普通公司、ETF 和场外基金选择不同图表集合。
6. Windows 中文字体回退已配置。

真实 smoke 已生成黄金 ETF 价格/收益/回撤图，以及贵州茅台估值和财务趋势图。

## 不负责的内容

1. Web 交互图。
2. 实时刷新。
3. 图表画线和缩放。
4. 同行散点和行业比较。
5. 自动嵌入报告。

## 当前缺口

1. 基准叠加。
2. 同行比较图。
3. 多期真实估值和财务历史产物。
4. 报告图表选择与引用。
