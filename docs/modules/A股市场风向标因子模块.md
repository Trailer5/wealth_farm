# A股市场风向标因子模块

## 职责

本模块把 A 股市场横截面、融资融券、ETF 份额、公开交易事件和披露持仓转换为可复查的市场状态因子。

## 目录

1. `src/market_analysis/`：市场宽度、成交拥挤度和大小盘相对强弱。
2. `src/factor_engineering/margin.py`：个股融资融券杠杆因子。
3. `src/fund_research/share_flow.py`：ETF 份额变化和估算净申购。
4. `src/factor_engineering/market_event.py`：龙虎榜、大宗、公告和互联互通披露因子。
5. `src/data_src/akshare/provider.py`：两融、ETF 份额/NAV、龙虎榜和大宗交易适配器。

## 当前能力

### 市场横截面

暂定 `a_share_market_v1` 已实现上涨家数占比、涨跌停家数差比率、站上20日均线比例、市场成交额标准分、等权组合超额收益和小盘相对强弱。结果保存 universe 生效日期、样本数和排除数量，不绑定伪造的单标的身份。

AkShare 适配器已新增当前市场活跃度快照、上证市场PB历史、申万市场表征和申万一级行业日频指标。当前市场活跃度只作为当日辅助观察，不持久化为历史宽度，也不进入长期回测。

`market_series_observations` 以长格式保存指数PE/PB、利率和后续宏观序列，分别记录观察日、可用日、方法口径、单位、来源和原始记录。不同PE/PB口径不得压成同一字段，历史查询可按 `available_at` 截断。

`IndexValuationSeriesService` 将静态PE、滚动PE、等权PE、中位数PE以及三类PB分别持久化，防止不同估值方法被压成一个不可审计字段。

`IndexFundamentalCalculator` 计算盈利收益率、股息率、PB、盈利收益率减十年国债的风险溢价，以及十年国债减最新 CPI 的描述性实际利率代理。估值趋势只比较同一方法，方法比较只接受同一观察日，不指定某种口径为“真值”。

最新 CPI 直接读取国家统计局数据发布页并保留发布日期；该入口只用于当前描述，不是时点历史归档，明确禁止进入历史回测。申万一级行业使用前一交易日共同样本流通市值权重计算当日贡献，并同时输出 PE、PB、股息率和成交额占比排序，不声称是特定指数历史归因。

### 指数基本面与申万行业截面

`src/market_analysis/fundamentals.py` 接受带 `available_at` 的冻结快照，计算指数盈利收益率、股息率、PB、股东收益代理、实际利率代理和股权风险溢价。收益率输出统一为 ratio：

1. 盈利收益率 = `1 / PE`。
2. 股东收益代理 = 盈利收益率 + 股息率；它只是估值与分红的简化代理，不等于实际股东总回报，也未计入回购和增发。
3. 实际利率代理 = 中国十年期国债收益率 - CPI；它只是 CPI 口径代理。
4. 股权风险溢价 = 盈利收益率 - 中国十年期国债收益率。

指数估值输入的股息率必须先归一化为 ratio。宏观输入明确支持 `percent`、`%` 和 `ratio`，计算结果统一转为 ratio。输出保留估值方法、公式口径和全部输入来源。

CPI 调用方必须提供真实发布日期对应的 `available_at`。没有真实发布日期的 CPI 不得用于历史回测；估值、CPI 或利率的 `available_at` 晚于评估日时直接拒绝，不能把后见数据降级成“缺值”继续计算。

`MarketIndustryAssessmentCalculator` 直接复用 `IndustryContributionCalculator`，用共同申万行业的前一日流通市值权重乘当日行业收益，并对当前截面的贡献、PE、PB、股息率和成交额占比排序。PE/PB 按从低到高，其余按从高到低；缺失项不进入对应排序。`IndustryFundamentalSnapshot.from_sw_record` 负责把现有 Provider 的百分比字段转为 ratio，不改变 Provider 契约。

行业结果只描述申万市场表征的当前截面，不代表任何特定指数的历史行业归因。若要做指数归因，仍需该指数逐期真实成分、权重及生效时间。

### 融资融券

暂定 `margin_daily_v1` 已实现融资余额变化率、融资买入强度和融资余额成交额比。AkShare 适配器统一沪深个股明细字段和 CNY 单位；数据不代表具体投资者身份。

### ETF资金流

暂定 `exchange_fund_flow_v1` 已实现 ETF 份额变化率和估算净申购额。份额来自沪深交易所数据，NAV 是估算参考；所有结果保留 `estimated`、拆分状态和来源，不称为国家队流入。

### 市场事件

暂定 `market_event_v1` 已实现龙虎榜、大宗交易、回购、增减持和解禁的窗口因子。营业部和机构席位只描述公开席位交易，不推断游资或国家队身份。

### 互联互通与披露持仓

暂定 `capital_flow_v1` 固定北向 2024-08-19 制度断点：断点前可使用历史净流入，断点后只允许成交活跃度、前十集中度和季度持仓。南向只作为港股风险偏好背景；国家队只接受官方披露持仓。

### 国家队ETF周级追踪

`state_capital_flow_v1` 使用正式基金中报、年报前十持有人确认国家队 ETF 身份，并按自然周聚合交易所 ETF 份额变化。确认持仓、确认方向和匿名代理分层输出，详细规则见 `国家队资金周级追踪模块.md`。

## 边界

1. 当前市场横截面计算器接受规范化输入，但全 A 历史 universe 和自动批量准备尚未完成。
2. 历史全A宽度不在当前开发路线内；当前股票池不得用于历史回填。
3. `FactorValue` 型结果只有在调用方提供真实 `asset_id` 时才能持久化。
4. 龙虎榜和大宗交易适配器来自第三方对交易所公开信息的汇总，不能替代官方证据。
5. 北向后制度公开数据和全部国家队 ETF 正式报告自动发现尚未完成；官方 PDF 表格解析已完成真实验证。
6. 所有事件和持仓从实际 `published_date` 生效，不允许未来数据回填。
7. CPI 若没有可验证的真实发布日期，只能用于当前观察，不得进入历史回测。
