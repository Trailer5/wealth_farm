# 因子与指标扩展手册

## 使用说明

本手册只记录当前代码能够实际计算或统计的因子。公式正确不等于具有预测力，策略使用前还必须检查数据来源、样本长度、版本和适用 profile。

标题采用 `代码 key：常用中文名`，中文名用于阅读，代码调用仍使用英文 key。

可信度标签：

- `公式已验证`：已用独立手算样本或数学不变量验证。
- `来源受限`：公式已验证，但 Provider、标的覆盖、报告期或字段质量可能阻塞。
- `研究性`：计算定义明确，但没有长样本、样本外或经济因果验证。

## 版本与审计结论

当前版本：

- `market_daily_v1`：严格校验 ISO 日期、正价格和重复日期。
- `a_share_market_v1`：按显式 scope、universe 和生效日计算 A 股市场横截面，不绑定单只标的。
- `risk_daily_v1`：日频总体方差、显式年化天数和无风险利率。
- `benchmark_daily_v1`：只使用双方前一观察日一致的收益区间，避免把错位跨日收益当成日收益。
- `margin_daily_v1`：沪深交易所融资融券明细规范化为 CNY 后计算日频杠杆指标。
- `market_event_v1`：只在显式日历窗口内聚合已披露市场事件，不无限延续事件状态。
- `capital_flow_v1`：按披露制度和 `published_date` 计算非单股互联互通与披露持仓指标。
- `state_capital_flow_v1`：以正式持有人报告确认 ETF 身份，计算周级匿名份额流、披露暴露加权代理、份额正向宽度、披露后最低减持份额下界和官方买入方向标记。
- `fundamental_v1`：装配阶段强制 `published_at <= as_of_date`，并补全市值相关证据链。
- `exchange_fund_metric_v1`：ETF 折溢价与官方综合费率。
- `exchange_fund_flow_v1`：ETF 份额变化及基于最近可用 NAV 的估算净申购额。
- `financial_institution_v1`：校验单位，并按 revision、披露时间确定同报告期字段。
- `commodity_sensitivity_v1`：严格价格校验，并只使用所有序列观察区间一致的收益。

历史变更：

- 当前日期契约、收益区间对齐、披露截止日守卫、单位与 revision 选择及严格价格校验等修正，均已直接纳入暂定 `v1`；本文只记录暂定 `v1` 的现行定义，不另保留兼容或发布历史。

审计边界：

1. 已验证公式和状态机，不代表因子具有未来收益预测能力。
2. `float` 型行情因子存在正常浮点误差；财务指标使用 `Decimal`。
3. 当前项目自有计算版本只接受暂定 `v1`；其他版本标签视为未定版阶段的非法残留。

2026-08-03 验证记录：

- 295 项单元测试通过，覆盖独立手算、边界和版本契约。
- 普通公司、ETF、金融机构和周期资源四条真实正式执行 smoke 均为 `complete`。
- 当前真实执行已产出 `market_daily_v1`、`risk_daily_v1`、`benchmark_daily_v1`、`fundamental_v1`、`financial_institution_v1`、`exchange_fund_metric_v1` 和 `commodity_sensitivity_v1`。
- 真实 smoke 只验证当前来源可用和链路可执行，不构成长样本有效性证明。

<a id="market"></a>
## 价格与技术

来源：规范化日线 `close`，代码位于 `src/factor_engineering/calculator.py`。这些是常见价格变换，没有唯一的理论发明者。当前不自动保证复权口径，必须从数据集和上游 Provider 确认。

<a id="drawdown"></a>
### `drawdown`：回撤

- 作用：衡量当前价格相对输入窗口最高收盘价的跌幅。
- 公式：`P_t / max(P_window) - 1`。
- 场景：当前价格位置、短期风险门禁。
- 限制：只表示当前回撤，不是历史最差回撤；不可与 `max_drawdown` 混用。
- 状态：`公式已验证`，`market_daily_v1`。

<a id="return-1d"></a>
### `return_1d`：单日收益率

- 作用：最近一个观察区间的简单收益。
- 公式：`P_t / P_(t-1) - 1`。
- 输入：至少两个有效正收盘价。
- 场景：短期价格确认；跨停牌或缺失日时代表相邻观察日收益，不必然是自然日收益。
- 状态：`公式已验证`，`market_daily_v1`。

<a id="sma-5"></a>
### `sma_5`：5日简单移动平均线

- 作用：平滑最近价格，作为短趋势基线。
- 公式：最近五个收盘价的算术平均。
- 单位：与价格相同，不是收益率。
- 限制：固定五个观察日，对长期估值没有解释力。
- 状态：`公式已验证`，`market_daily_v1`。

<a id="momentum-5"></a>
### `momentum_5`：5日动量

- 作用：衡量五个收益区间的价格动量。
- 公式：`P_t / P_(t-5) - 1`，需要六根日线。
- 场景：短期趋势、催化剂价格确认。
- 限制：窗口短、换手敏感，不可解释为基本面改善。
- 状态：`公式已验证`、`研究性`，`market_daily_v1`。

<a id="volatility-5"></a>
### `volatility_5`：5日年化波动率

- 作用：衡量最近五个日收益的短期波动。
- 公式：`population_std(r_1...r_5) × sqrt(252)`。
- 场景：短期异常波动和风险门禁。
- 限制：五日样本极短；使用总体方差 `N`，不是样本方差 `N-1`。
- 状态：`公式已验证`、`研究性`，`market_daily_v1`。

<a id="a-share-market"></a>
## A股市场横截面

来源：规范化 A 股当日横截面、历史成交额序列和显式基准收益，代码位于 `src/market_analysis/`。输出是独立的 `market_analysis` 市场快照，不写成单只标的 `FactorValue`。每个结果必须保存 `scope_id`、`universe_id`、`universe_version`、`universe_effective_date`、有效样本数及非交易/缺失排除数；当前 universe 不得回填为历史成分。涨跌停状态由上游提供，计算器不按板块或日期猜测涨跌停阈值。

<a id="advance-ratio"></a>
### `advance_ratio`：上涨家数占比

- 作用：描述当日有效市场成员中价格上涨的广度。
- 公式：`上涨有效标的数 / 有效标的数`；上涨指相邻有效观察日简单收益大于零。
- 来源：规范化横截面的当日与前一观察日收盘价。
- 时间尺度：单交易日横截面；缺日时单标的收益仍是相邻观察日收益。
- 限制：停牌、缺失价格和 universe 选择会改变分母；公式正确不代表可预测未来收益。
- 版本：`a_share_market_v1`。
- 身份边界：市场 scope 指标，不绑定单只资产，也不识别投资者身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="limit-up-down-spread"></a>
### `limit_up_down_spread`：涨跌停家数差比率

- 作用：衡量当日涨停与跌停数量的相对差异。
- 公式：`(涨停数 - 跌停数) / 有效标的数`。
- 来源：规范化横截面及上游提供的 `limit_state`。
- 时间尺度：单交易日横截面。
- 限制：计算器不猜主板、创业板、科创板或特殊处理标的的阈值；缺失或错误状态会直接影响结果，且不证明后续方向。
- 版本：`a_share_market_v1`。
- 身份边界：市场情绪统计，不绑定单只资产，不代表任何投资者群体的行为。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="above-ma20-ratio"></a>
### `above_ma20_ratio`：站上20日均线比例

- 作用：衡量有效成员中收盘价高于自身20日均线的比例。
- 公式：`收盘价高于最近20个有效收盘价均值的标的数 / 具备20日历史的有效标的数`。
- 来源：规范化横截面及各成员最近20个有效收盘价。
- 时间尺度：单交易日横截面，均线窗口为20个观察日。
- 限制：历史不足成员单独排除并记录；不自动保证复权一致，技术广度不等于未来收益预测。
- 版本：`a_share_market_v1`。
- 身份边界：市场 scope 指标，不是单股技术因子，也不描述资金身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="market-turnover-amount-zscore"></a>
### `market_turnover_amount_zscore`：市场成交额标准分

- 作用：比较当日市场成交活跃度与显式历史基线的偏离。
- 公式：`(当日有效成员成交额合计 - 历史均值) / 历史总体标准差`。
- 来源：规范化横截面成交额及参数中的历史市场成交额合计序列。
- 时间尺度：当日横截面对显式历史日频窗口；历史样本数随结果保存。
- 限制：历史总体标准差必须大于零；universe、金额单位和历史窗口必须一致，标准分高低不保证后续行情。
- 版本：`a_share_market_v1`。
- 身份边界：市场成交活跃度，不绑定单只资产，也不推断成交参与者。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="equal-weight-excess"></a>
### `equal_weight_excess`：等权组合超额收益

- 作用：衡量当日有效市场成员等权组合相对显式基准的表现。
- 公式：`有效成员单日收益算术均值 - 同期基准收益`。
- 来源：规范化横截面的相邻观察日收盘价和显式传入的基准收益。
- 时间尺度：单交易日或相邻有效观察区间。
- 限制：不是复合累计超额收益或回归 Alpha；基准、缺失样本和停牌处理会影响结果，单日超额不证明预测力。
- 版本：`a_share_market_v1`。
- 身份边界：市场等权组合结果，不绑定单只资产或真实可交易账户。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="small-cap-relative-strength"></a>
### `small_cap_relative_strength`：小盘相对强弱

- 作用：比较显式小盘组与大盘组的当日等权收益。
- 公式：`small 组单日收益均值 - large 组单日收益均值`。
- 来源：规范化横截面收益及上游提供的 `size_bucket`。
- 时间尺度：单交易日或相邻有效观察区间。
- 限制：两组都必须有有效样本；当前分组依赖上游市值数据和规则，不能把当前 universe 或当前分组回填到历史，结果不保证延续。
- 版本：`a_share_market_v1`。
- 身份边界：市场分组相对表现，不是单股因子，也不等同风格因子收益回归。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="sse-market-timing"></a>
## 上证指数多周期择时

以下指标由 `src/strategy/sse_market_timing.py` 在上证指数策略内按需计算，暂不作为通用 `FactorValue` 持久化。策略版本为 `v1`，所有信号从下一交易日生效。

<a id="timing-rsi"></a>
### `rsi`：相对强弱指数

- 公式：最近14个价格变化中，`100 - 100 / (1 + 上涨额合计 / 下跌额绝对值合计)`；无下跌为100，无上涨为0，完全不变为50。
- 作用：短期超买超卖位置证据，默认低于等于30支持低位、高于等于70支持高位。
- 限制：固定阈值会钝化；2005–2026复合事件研究未证明其短期方向优势。
- 状态：`公式已验证`、`研究性`。

<a id="timing-price-percentile"></a>
### `price_percentile`：窗口价格分位

- 公式：当前收盘价在20、120或1008个交易日窗口中的经验分位。
- 作用：分别描述短期、中短期和约四年价格位置。
- 限制：只描述相对位置；创新高或创新低可以持续，不能单独作为反转信号。
- 状态：`公式已验证`、`研究性`。

<a id="timing-close-zscore"></a>
### `close_zscore`：收盘价标准分

- 公式：`(当前收盘价 - 20日均值) / 20日总体标准差`。
- 作用：识别短期价格偏离是否达到极端区域。
- 限制：价格非平稳，标准分不是正态概率；标准差为零时停止计算。
- 状态：`公式已验证`、`研究性`。

<a id="timing-qvix-percentile"></a>
### `qvix_percentile`：期权波动率分位

- 公式：50ETF QVIX 收盘值在最近252个有效观测中的经验分位。
- 作用：极高分位辅助短期恐慌低位，极低分位辅助过热高位。
- 来源：AkShare 对第三方 QVIX 数据的适配，不是交易所官方波动率指数。
- 限制：只作补充证据；缺失时降低置信度但不伪造数据。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="timing-sma-ratio"></a>
### `sma_ratio`：均线偏离率

- 公式：`当前收盘价 / N日简单均线 - 1`，中短期默认N=60；中长期同时记录60日确认和200日趋势。
- 作用：区分价格极值区域与已经发生的趋势确认。
- 限制：均线滞后，只能确认而不能预测精确拐点。
- 状态：`公式已验证`、`研究性`。

<a id="timing-pe-percentile"></a>
### `pe_percentile`：四年市场市盈率分位

- 公式：上证市场平均市盈率在最近4个自然年有效观测中的经验分位，至少要求48个观测。
- 作用：为中长期高低位提供估值锚，不用单股PE替代指数估值。
- 来源：AkShare `stock_market_pe_lg(symbol="上证")`；当前历史是低频序列，因此不能假设每日一条。
- 限制：行业权重和估值中枢会变化；允许最多45个自然日陈旧度并显式记录数据不足。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="timing-erp-percentile"></a>
### `erp_percentile`：四年股权风险溢价分位

- 公式：`ERP = 1 / 上证市场PE - 中国10年期国债收益率 / 100`，再计算4年经验分位。
- 作用：辅助比较权益盈利收益率与无风险利率。
- 限制：PE和利率中枢变化会使ERP长期钝化，代码将其设为可选证据而非硬门槛。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="timing-window-location"></a>
### `drawdown_from_high` / `rise_from_low`：窗口回撤与涨幅

- 公式：`当前价 / 窗口最高价 - 1`；`当前价 / 窗口最低价 - 1`。
- 作用：中短期使用120日窗口，中长期使用252日窗口，确认当前位置是否经历足够幅度的下跌或上涨。
- 限制：窗口起点敏感，幅度条件必须与估值、价格位置和反转确认共同使用。
- 状态：`公式已验证`、`研究性`。

<a id="risk"></a>
## 风险与风险调整

来源：日线价格，代码位于 `src/factor_engineering/risk.py`。默认 `annualization_days=252`、`risk_free_rate=0`，方差统一采用总体方差。所有年化口径必须连同参数读取。

<a id="daily-return"></a>
### `daily_return`：日收益率

- 公式：`P_t / P_(t-1) - 1`，逐观察区间输出。
- 作用：风险、滚动统计和回测的基础收益序列。
- 限制：上游缺日会使区间变长；单资产风险模块不会猜交易日。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="cumulative-return"></a>
### `cumulative_return`：累计收益率

- 公式：`P_t / P_0 - 1`。
- 作用：描述输入窗口内从起点持有至当前的累计收益。
- 限制：对起点敏感，不代表年化收益。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="drawdown-series"></a>
### `drawdown_series`：回撤序列

- 公式：`P_t / running_max(P_0...P_t) - 1`。
- 作用：绘制回撤路径并识别峰值、谷值和修复。
- 限制：窗口起点以前的历史峰值不可见。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="rolling-return"></a>
### `rolling_return_{N}d`：N日滚动收益率

- 公式：`P_t / P_(t-N) - 1`。
- 作用：比较不同长度的滚动收益。
- 窗口：由 `rolling_windows` 显式给出，名称中的 `N` 是收益区间数。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="rolling-volatility"></a>
### `rolling_annualized_volatility_{N}d`：N日滚动年化波动率

- 公式：最近 `N` 个日收益的总体标准差乘 `sqrt(annualization_days)`。
- 作用：识别风险状态变化。
- 限制：短窗口估计噪声大；不同年化参数的值不可直接比较。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="rolling-sharpe"></a>
### `rolling_sharpe_{N}d`：N日滚动夏普比率

- 公式：`(mean(r)-r_f,daily) × T / annualized_volatility`。
- 作用：观察滚动风险调整后收益。
- 输出条件：窗口波动必须大于零。
- 状态：`公式已验证`、`研究性`，`risk_daily_v1`。

<a id="annualized-return"></a>
### `annualized_return`：年化收益率

- 公式：`(P_end / P_start)^(T / n_returns) - 1`。
- 作用：把窗口几何收益转换为年化收益。
- 限制：短窗口外推会极不稳定；不能理解为未来收益预期。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="annualized-volatility"></a>
### `annualized_volatility`：年化波动率

- 公式：`population_std(daily_returns) × sqrt(T)`。
- 作用：衡量总波动风险，是 Sharpe 分母和策略否决项。
- 限制：将收益近似为同频日收益，不能捕捉跳跃和尾部全部风险。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="downside-volatility"></a>
### `downside_volatility`：下行波动率

- 公式：`sqrt(sum(min(r-r_f,daily, 0)^2) / N) × sqrt(T)`。
- 作用：只惩罚低于最低可接受收益的区间。
- 定义选择：分母是全部观察数 `N`，不是仅负收益个数；输出已经年化。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="max-drawdown"></a>
### `max_drawdown`：最大回撤

- 公式：窗口内所有 `P_t / running_peak_t - 1` 的最小值。
- 作用：估计历史峰谷资本损失，是多个策略的硬风险输入。
- 参数：同时保存 peak、trough、recovery 日期。
- 限制：窗口外峰值不可见；历史回撤不等于未来最大损失。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="drawdown-duration"></a>
### `drawdown_duration_days`：回撤持续天数

- 公式：最大回撤峰值到修复日；未修复时到窗口末日的日历日差。
- 作用：衡量资金被套和修复持续时间。
- 限制：单位是日历日，不是交易日。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="drawdown-recovery"></a>
### `drawdown_recovery_days`：回撤修复天数

- 公式：最大回撤谷底到重新达到峰值的日历日差。
- 输出条件：回撤必须已经修复。
- 限制：未修复时不输出，不应用零代替。
- 状态：`公式已验证`，`risk_daily_v1`。

<a id="sharpe-ratio"></a>
### `sharpe_ratio`：夏普比率

- 作用：单位总波动对应的年化超额收益。
- 公式：`(mean(r)-r_f,daily) × T / (std_population(r) × sqrt(T))`。
- 历史：Sharpe 1966 年称为 reward-to-variability ratio，后通称 Sharpe Ratio。
- 限制：对收益分布、频率和样本长度敏感；零波动时不输出。
- 状态：`公式已验证`、`研究性`，`risk_daily_v1`。

<a id="sortino-ratio"></a>
### `sortino_ratio`：索提诺比率

- 作用：只使用下行偏差衡量风险调整后收益。
- 公式：年化算术超额收益除以年化 `downside_volatility`。
- 历史：当前定义参考 Sortino 与 Price 1994 年 downside-risk 框架。
- 限制：最低可接受收益当前等于无风险利率；不同实现的 downside 分母可能不同。
- 状态：`公式已验证`、`研究性`，`risk_daily_v1`。

<a id="calmar-ratio"></a>
### `calmar_ratio`：卡玛比率

- 作用：比较复合年化收益与最大回撤。
- 公式：`annualized_return / abs(max_drawdown)`。
- 历史：Terry W. Young 1991 年提出，原始应用常用 36 个月窗口；本项目使用显式输入窗口。
- 限制：没有回撤时不输出；短窗口 Calmar 不应与原始长期口径混同。
- 状态：`公式已验证`、`研究性`，`risk_daily_v1`。

<a id="benchmark"></a>
## 基准与相对表现

来源：标的和明确绑定的指数或 ETF 代理日线，代码位于 `src/benchmark_analysis/`。`benchmark_daily_v1` 只保留双方“当前观察日和前一观察日都一致”的收益区间，不填充缺失价格。

<a id="asset-cumulative-return"></a>
### `asset_cumulative_return`：标的累计收益率

- 公式：按保留的匹配收益区间依次复利。
- 作用：显示标的在可比区间中的累计表现。
- 限制：被排除的错位区间不会进入累计值。
- 状态：`公式已验证`，`benchmark_daily_v1`。

<a id="benchmark-cumulative-return"></a>
### `benchmark_cumulative_return`：基准累计收益率

- 公式：按相同匹配区间复利基准收益。
- 作用：为标的累计表现提供同区间参照。
- 状态：`公式已验证`，`benchmark_daily_v1`。

<a id="active-return"></a>
### `active_return`：主动收益率

- 公式：每个匹配区间 `r_asset - r_benchmark`。
- 作用：跟踪误差和信息比率的基础序列。
- 状态：`公式已验证`，`benchmark_daily_v1`。

<a id="asset-total-return"></a>
### `asset_total_return`：标的总收益率

- 公式：全部保留匹配区间的标的复合收益。
- 作用：窗口内可比总收益。
- 状态：`公式已验证`，`benchmark_daily_v1`。

<a id="benchmark-total-return"></a>
### `benchmark_total_return`：基准总收益率

- 公式：全部保留匹配区间的基准复合收益。
- 作用：窗口内基准总收益。
- 状态：`公式已验证`，`benchmark_daily_v1`。

<a id="excess-total-return"></a>
### `excess_total_return`：累计超额收益率

- 公式：`asset_total_return - benchmark_total_return`。
- 作用：判断窗口内是否跑赢明确基准。
- 限制：是收益率之差，不是相对比值，也不代表 Alpha。
- 状态：`公式已验证`，`benchmark_daily_v1`。

<a id="tracking-error"></a>
### `tracking_error`：跟踪误差

- 公式：`population_std(active_returns) × sqrt(T)`。
- 作用：衡量相对基准偏离的稳定程度。
- 历史：行业通常称 active risk 或 tracking risk。
- 限制：依赖正确基准和足够匹配区间；总体方差口径需与外部系统对齐。
- 状态：`公式已验证`、`来源受限`，`benchmark_daily_v1`。

<a id="information-ratio"></a>
### `information_ratio`：信息比率

- 公式：`mean(active_returns) × T / tracking_error`。
- 作用：衡量每单位主动风险获得的年化主动收益。
- 输出条件：跟踪误差大于零。
- 限制：对短样本和基准选择非常敏感。
- 状态：`公式已验证`、`研究性`，`benchmark_daily_v1`。

<a id="beta"></a>
### `beta`：贝塔系数

- 公式：`Cov_population(r_asset, r_benchmark) / Var_population(r_benchmark)`。
- 作用：衡量标的对基准收益变化的线性敏感度。
- 来源历史：沿用市场模型和 CAPM 的回归斜率思想。
- 限制：基准方差为零时不输出；相关不代表因果。
- 状态：`公式已验证`、`研究性`，`benchmark_daily_v1`。

<a id="alpha"></a>
### `alpha`：阿尔法

- 公式：`[mean(r_a)-r_f,daily-beta×(mean(r_b)-r_f,daily)] × T`。
- 作用：估计 CAPM 单因子解释后的年化截距。
- 历史：参考 Jensen 1968 年基金绩效度量。
- 限制：当前是均值形式而非带显著性检验的完整回归；不能单独证明选股能力。
- 状态：`公式已验证`、`研究性`，`benchmark_daily_v1`。

<a id="correlation"></a>
### `correlation`：相关系数

- 公式：`Cov(r_a,r_b) / [Std(r_a)×Std(r_b)]`。
- 作用：衡量匹配收益区间中的线性同向程度。
- 输出条件：双方标准差均大于零。
- 限制：不等于 Beta，也不代表因果或稳定关系。
- 状态：`公式已验证`、`研究性`，`benchmark_daily_v1`。

<a id="margin"></a>
## 融资融券

来源：沪深交易所融资融券明细经 AkShare 正式 adapter 规范化，金额统一为 `CNY`，代码位于 `src/factor_engineering/margin.py`。计算不做缺失值填充，输入来源、起止日期、窗口和单位随结果保存。

<a id="margin-balance-change"></a>
### `margin_balance_change`：融资余额变化率

- 作用：衡量标的融资余额在显式窗口内的相对变化。
- 公式：`(当前融资余额 - N日前融资余额) / N日前融资余额`。
- 来源：沪深交易所明细经 AkShare 正式 adapter 取得的规范化融资余额。
- 时间尺度：日频，默认 `N=5` 个有效记录间隔，窗口参数显式保存。
- 限制：需要至少 `N+1` 条记录且期初融资余额大于零；缺日会使观察区间变长，历史变化不等于未来价格方向。
- 版本：`margin_daily_v1`。
- 身份边界：证券维度的汇总融资余额，不提供或推断投资者身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="margin-buy-ratio"></a>
### `margin_buy_ratio`：融资买入强度

- 作用：衡量当日融资买入额相对标的成交额的强度。
- 公式：`当日融资买入额 / 同日成交额`。
- 来源：沪深交易所融资融券明细经 AkShare 正式 adapter 取得融资买入额，同日规范化行情提供成交额；金额均为 `CNY`。
- 时间尺度：单交易日。
- 限制：同日成交额必须大于零且不做缺失填充；它是金额比例，不代表净融资流入，也不证明价格预测有效。
- 版本：`margin_daily_v1`。
- 身份边界：证券层面的公开汇总交易数据，不识别账户、机构或个人。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="margin-balance-to-amount"></a>
### `margin_balance_to_amount`：融资余额成交额比

- 作用：比较融资存量与当日交易活跃度。
- 公式：`当日融资余额 / 同日成交额`。
- 来源：沪深交易所融资融券明细经 AkShare 正式 adapter 取得融资余额，同日规范化行情提供成交额；金额均为 `CNY`。
- 时间尺度：单交易日快照。
- 限制：分子是存量、分母是单日流量，数值不是持仓占比；同日成交额必须大于零，当前未实现融资余额/流通市值。
- 版本：`margin_daily_v1`。
- 身份边界：证券层面的杠杆存量指标，不代表任何已识别投资者群体。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="market-event"></a>
## 市场事件

来源：带原始 `source`、交易日和披露日的规范化龙虎榜、大宗交易及公告记录，代码位于 `src/factor_engineering/market_event.py`。计算只聚合截至 `as_of_date` 已披露且交易日在显式窗口内的记录，窗口是包含首尾的日历日；事件不会无限 `forward-fill`。席位字段只保留上游披露类别，不据此推断游资或国家队。

<a id="lhb-listing-count"></a>
### `lhb_listing_count`：龙虎榜上榜次数

- 作用：统计标的在窗口内已披露的龙虎榜上榜记录数。
- 公式：`count(窗口内可见的 lhb_listing 记录)`。
- 来源：规范化龙虎榜记录及其原始来源标识。
- 时间尺度：显式 `window_days` 日历日窗口，且 `published_date <= as_of_date`。
- 限制：重复或漏收记录会影响计数；上榜频率不等于后续收益预测。
- 版本：`market_event_v1`。
- 身份边界：记录证券上榜事件，不识别交易者，也不把席位归因为游资或国家队。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="lhb-net-buy-amount"></a>
### `lhb_net_buy_amount`：龙虎榜净买额

- 作用：汇总窗口内可见龙虎榜记录的净买入金额。
- 公式：`sum(有效记录净买额)`。
- 来源：规范化龙虎榜记录中的 `net_buy_amount` 和原始来源标识。
- 时间尺度：显式日历日窗口，按披露可见性生效。
- 限制：只汇总存在净买额字段的记录，不填补缺失；历史净买额不保证未来价格表现。
- 版本：`market_event_v1`。
- 身份边界：证券事件金额汇总，不代表某类实名投资者的净买入。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="lhb-net-buy-ratio"></a>
### `lhb_net_buy_ratio`：龙虎榜净买额占成交额

- 作用：把窗口内龙虎榜净买额按同组可用成交额归一化。
- 公式：`sum(净买额) / sum(对应龙虎榜记录成交额)`。
- 来源：同时具备 `net_buy_amount` 和正 `turnover_amount` 的规范化龙虎榜记录。
- 时间尺度：显式日历日窗口，按披露可见性生效。
- 限制：分子分母只使用字段同时可用的记录；不是全市场成交额占比，也不证明预测有效。
- 版本：`market_event_v1`。
- 身份边界：龙虎榜事件比例，不识别或推断交易者身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="institution-seat-net-buy-ratio"></a>
### `institution_seat_net_buy_ratio`：机构席位净买额占比

- 作用：衡量窗口内披露为机构席位的净买额相对对应成交额。
- 公式：`sum(机构席位净买额) / sum(对应龙虎榜记录成交额)`。
- 来源：同时具备机构席位净买额和正成交额的规范化龙虎榜记录。
- 时间尺度：显式日历日窗口，按披露日可见。
- 限制：席位标签来自上游披露，不代表穿透后的最终持有人；缺失记录不填补，比例不保证未来收益。
- 版本：`market_event_v1`。
- 身份边界：机构席位类别不等于已确认机构投资者，更不等于国家队。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="broker-branch-net-buy-ratio"></a>
### `broker_branch_net_buy_ratio`：营业部席位净买额占比

- 作用：衡量窗口内营业部席位净买额相对对应成交额。
- 公式：`sum(营业部席位净买额) / sum(对应龙虎榜记录成交额)`。
- 来源：同时具备营业部席位净买额和正成交额的规范化龙虎榜记录。
- 时间尺度：显式日历日窗口，按披露日可见。
- 限制：营业部可能服务多类客户，席位金额不能直接归因为特定资金；缺失记录不填补。
- 版本：`market_event_v1`。
- 身份边界：营业部席位行为不等于游资或国家队行为。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="block-trade-amount"></a>
### `block_trade_amount`：大宗交易成交额

- 作用：汇总窗口内已披露的大宗交易金额。
- 公式：`sum(有效大宗交易成交额)`。
- 来源：规范化大宗交易记录中的 `amount` 和原始来源标识。
- 时间尺度：显式日历日窗口，按披露日可见。
- 限制：只汇总金额字段存在的记录，不补缺；成交额本身不表示买卖方向或后续价格影响。
- 版本：`market_event_v1`。
- 身份边界：证券交易事件汇总，不识别交易双方最终身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="block-trade-discount"></a>
### `block_trade_discount`：大宗交易折价率

- 作用：衡量窗口内大宗交易成交价相对参考收盘价的加权折溢价。
- 公式：`weighted_mean(1 - 成交价 / 参考收盘价)`，优先以成交额加权。
- 来源：同时具备成交价和正参考收盘价的规范化大宗交易记录。
- 时间尺度：显式日历日窗口，按披露日可见。
- 限制：缺少 `turnover_amount` 时实现依次使用 `amount`、等权作为权重回退；参考收盘价口径必须审查，正折价不代表未来收益。
- 版本：`market_event_v1`。
- 身份边界：交易定价指标，不据此识别买方、卖方或资金性质。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="block-trade-float-cap-ratio"></a>
### `block_trade_float_cap_ratio`：大宗交易成交额占流通市值

- 作用：把窗口内大宗交易规模相对最近可用流通市值归一化。
- 公式：`窗口内有效大宗交易成交额合计 / 最新可用流通市值`。
- 来源：规范化大宗交易金额和记录中最近可用的正流通市值。
- 时间尺度：显式日历日事件窗口配合分母记录日期。
- 限制：分母时点随参数保存但可能与全部交易日不完全一致；当前真实流通市值数据接线仍受限，比例不表示持股比例。
- 版本：`market_event_v1`。
- 身份边界：证券交易规模指标，不穿透交易主体身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="disclosure-buyback-flag"></a>
### `disclosure_buyback_flag`：回购公告标记

- 作用：标记窗口内是否存在截至截止日已披露的回购公告。
- 公式：存在可见回购记录时输出 `1`；不存在时不输出该因子，不以 `0` 伪造已核验状态。
- 来源：规范化回购公告记录及原始披露来源。
- 时间尺度：显式日历日窗口；公告从 `published_date` 起可用。
- 限制：只表示公告出现，不表示回购已实施、金额完成或价格会受益；不无限延续标记。
- 版本：`market_event_v1`。
- 身份边界：公司披露事件，不是市场参与者身份或资金流认证。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="disclosure-holder-change-flag"></a>
### `disclosure_holder_change_flag`：股东增减持公告标记

- 作用：标记窗口内是否存在截至截止日已披露的股东增减持公告。
- 公式：存在可见股东增减持记录时输出 `1`；不存在时不输出该因子。
- 来源：规范化股东增减持公告记录及原始披露来源。
- 时间尺度：显式日历日窗口；公告从 `published_date` 起可用。
- 限制：标记不区分计划、进展和完成状态，也不自动判断方向或金额；不无限延续。
- 版本：`market_event_v1`。
- 身份边界：只采用公告披露的股东事件，不从席位或匿名交易反推股东身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="lock-up-release-announced-flag"></a>
### `lock_up_release_announced_flag`：解禁公告标记

- 作用：标记窗口内是否存在截至截止日已披露的限售股解禁公告。
- 公式：存在可见解禁公告记录时输出 `1`；不存在时不输出该因子。
- 来源：规范化解禁公告记录及原始披露来源。
- 时间尺度：显式日历日窗口；公告从 `published_date` 起可用。
- 限制：公告出现不等于实际卖出或形成抛压；标记不无限延续，具体解禁规模仍需原始证据。
- 版本：`market_event_v1`。
- 身份边界：公司证券供给事件，不识别实际卖出主体或资金身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="capital-flow"></a>
## 互联互通与披露持仓

来源：带 `scope`、观察日、`published_date`、披露制度和原始来源的规范化记录，代码位于 `src/factor_engineering/market_event.py`。输出为带 `scope_id` 的 `CapitalFlowFactorValue`，不是单股 `FactorValue`。所有记录从 `published_date` 起才可使用；北向日度净流入以 `2024-08-19` 为制度断点，该日及以后禁止继续输出北向净流入。匿名 ETF 份额流只能作为估算市场流量，不能确认国家队身份。

<a id="northbound-net-flow-pre-20240819"></a>
### `northbound_net_flow_pre_20240819`：北向历史净流入

- 作用：保留北向日度净流入仍公开期间的历史观察值。
- 公式：取截至截止日最新可见记录的披露 `net_flow`，不重新推导。
- 来源：北向 `daily_net_flow_pre_20240819` 制度下的规范化公开记录及其原始来源。
- 时间尺度：日频历史值，仅允许观察日早于 `2024-08-19`，并从 `published_date` 起生效。
- 限制：`2024-08-19` 及以后北向净流入不可用，禁止跨断点延续、估算或用成交额代替；当前公开数据抓取接线仍未完成。
- 版本：`capital_flow_v1`。
- 身份边界：互联互通 scope 级流量，不绑定单只 A 股，也不识别最终投资者。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="northbound-turnover"></a>
### `northbound_turnover`：北向成交活跃度

- 作用：在净流入停止公开后保留可观察的北向成交活跃程度。
- 公式：取截至截止日最新可见记录的披露成交额 `turnover`。
- 来源：北向 `daily_turnover_post_20240819` 制度下的规范化公开记录及其原始来源。
- 时间尺度：日频，观察日从 `2024-08-19` 起，并从 `published_date` 起生效。
- 限制：成交额没有净方向，不能换算为净流入；当前公开数据抓取接线仍未完成，活跃度也不证明后续收益。
- 版本：`capital_flow_v1`。
- 身份边界：互联互通 scope 级成交统计，不绑定单只证券或穿透投资者身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="northbound-top10-concentration"></a>
### `northbound_top10_concentration`：北向前十活跃证券成交集中度

- 作用：衡量北向成交额向前十活跃证券集中的程度。
- 公式：`前十活跃证券成交额 / 北向总成交额`。
- 来源：同一北向日度成交披露中的 `top10_turnover` 与正 `turnover`。
- 时间尺度：日频，观察日从 `2024-08-19` 起，并从 `published_date` 起生效。
- 限制：只反映成交集中度，不表示净买入方向、持仓集中度或未来收益；当前公开数据抓取接线仍未完成。
- 版本：`capital_flow_v1`。
- 身份边界：互联互通 scope 级结构指标，不把活跃证券或成交账户识别为特定资金。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="northbound-quarterly-holding-ratio"></a>
### `northbound_quarterly_holding_ratio`：北向季度持股比例

- 作用：记录北向资金按季度披露的持股比例。
- 公式：取截至截止日最新可见季度记录的披露 `holding_ratio`。
- 来源：北向 `quarterly_holding` 制度下的规范化官方披露记录。
- 时间尺度：季度观察值，从对应 `published_date` 起生效，不按报告期提前可用。
- 限制：季度低频数据不能当作日度流量；当前公开数据抓取接线仍未完成，历史持股比例不代表未来增减持。
- 版本：`capital_flow_v1`。
- 身份边界：北向 scope 级披露持仓，不绑定单只 A 股 `FactorValue`，也不穿透最终持有人。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="southbound-net-flow"></a>
### `southbound_net_flow`：南向净流入

- 作用：提供港股市场风险偏好的背景观察。
- 公式：取截至截止日最新可见南向日度记录的披露 `net_flow`。
- 来源：南向 `daily_net_flow` 制度下的规范化公开记录及其原始来源。
- 时间尺度：日频，从 `published_date` 起生效。
- 限制：只作港股风险偏好背景，参数固定记录 `a_share_direct_flow=false`；不能解释为 A 股直接资金流或预测信号。
- 版本：`capital_flow_v1`。
- 身份边界：南向 scope 级流量，不绑定单只 A 股或确认投资者身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="state-disclosed-holder-ratio"></a>
### `state_disclosed_holder_ratio`：国家队披露持股比例

- 作用：记录经官方披露确认的国家队白名单主体持股比例。
- 公式：取截至截止日最新可见官方披露记录的 `holding_ratio`。
- 来源：仅接受官方披露及国家队主体白名单匹配后的 `disclosed_holder` 记录。
- 时间尺度：按披露报告期或观察日记录，从 `published_date` 起生效。
- 限制：该因子的全市场连续数据接线仍未完成；未通过官方披露白名单匹配时不得产出，匿名 ETF 流量不能替代披露持仓。
- 版本：`capital_flow_v1`。
- 身份边界：只确认白名单官方披露主体；席位、营业部、ETF 份额变化或推测性标签均不能证明国家队身份。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="state-etf-weekly"></a>
## 国家队ETF周级追踪

来源：正式中报或年报的前十持有人报告、交易所 ETF 日度总份额与参考 NAV、国家队核心实体官方买入公告，代码位于 `src/state_capital_flow/`。正式报告链路现支持上交所按 ETF 代码直连发现、巨潮补充、PDF 解析和有上限可续跑回填。ETF 身份只允许由正式中报或年报前十持有人确认；详细证据层级、实体范围和持久化边界见[国家队资金周级追踪模块.md](国家队资金周级追踪模块.md)。

共同时间与证据规则：

- 每项周级结果保存 `week_start`、`week_end`、`estimated_for_date`、`available_at` 和覆盖率；`estimated_for_date` 对应该自然周周末，结果只能从 `available_at` 起使用。
- 前十持有人名单退出只表示后续报告未列示，不能把持仓补为零。
- ETF 总份额包含全部投资者，匿名份额变化不能确认国家队账户交易。
- 匿名金额、暴露加权金额和份额宽度属于 `anonymous_proxy`；披露后最低减持份额属于 `confirmed_lower_bound`；官方买入公告周标记属于 `confirmed_direction`。

<a id="state-held-etf-weekly-anonymous-flow-cny"></a>
### `state_held_etf_weekly_anonymous_flow_cny`：国家队持有ETF周级匿名净申购估算额

- 作用：汇总已由正式持有人报告确认身份的 ETF 周级总份额变化对应的估算金额。
- 公式：对各有效 ETF 计算 `(当前周末总份额 - 上一可用周末总份额) × 当前参考 NAV`，再对结果求和。
- 时间尺度：自然周；当前周和上一可用周分别取各周最后一个可见交易日。
- 证据层：`anonymous_proxy`。
- 限制：这是 ETF 全体投资者份额变化形成的估算值，不是国家队确认流入；NAV 时点和成员覆盖会影响结果。
- 版本：`state_capital_flow_v1`。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="state-exposure-weighted-weekly-proxy-cny"></a>
### `state_exposure_weighted_weekly_proxy_cny`：国家队披露暴露加权周级代理

- 作用：按最新正式报告披露的核心国家队持有比例，对国家队持有 ETF 的匿名周级流量进行透明加权。
- 公式：对各有效 ETF 计算 `匿名周级流量 × 最新正式报告中的核心国家队持有比例`，再对结果求和。
- 参数：明确保存 `pro_rata_assumption=true`，并保存实际使用的持有比例和覆盖率。
- 证据层：`anonymous_proxy`。
- 限制：按比例加权是假设，不是账户归因，也不是国家队确认买卖金额。
- 版本：`state_capital_flow_v1`。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="state-held-etf-weekly-positive-breadth"></a>
### `state_held_etf_weekly_positive_breadth`：国家队持有ETF周级份额正向宽度

- 作用：衡量已确认国家队持有 ETF 中，周级总份额增加的横截面广度。
- 公式：`份额增加的有效 ETF 数 / 有效 ETF 数`。
- 时间尺度：使用与周级匿名流量相同的当前周末和上一可用周末份额对。
- 证据层：`anonymous_proxy`。
- 限制：份额增加只表示 ETF 产品总份额上升，不能识别申购者或国家队交易方向。
- 版本：`state_capital_flow_v1`。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="state-minimum-reduction-since-disclosure-shares"></a>
### `state_minimum_reduction_since_disclosure_shares`：国家队披露后最低减持份额

- 作用：当 ETF 总份额已经低于上期国家队合计持仓时，给出国家队合计至少已经减持的可证明下界。
- 公式：对每只已由正式持有人报告确认核心国家队持仓的 ETF，计算 `max(0, 上期披露核心国家队合计持有份额 - 当前ETF总份额)`，再跨 ETF 求和。
- 输出条件：只在上期披露持仓与当前 ETF 总份额的份额单位连续性已确认时输出。
- 可用时间：`available_at` 使用最新持有人报告和 ETF 观察的最晚可用日期。
- 证据层：`confirmed_lower_bound`（`evidence_tier=confirmed_lower_bound`）。
- 身份边界：只给出核心国家队合计减持的下界，不把减持份额分配给任何具体实体。
- 限制：结果为 `0` 只表示当前总份额没有迫使下界为正，不表示国家队没有减持；该指标是份额数量，不是成交金额。
- 版本：`state_capital_flow_v1`。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="state-purchase-confirmed-flag"></a>
### `state_purchase_confirmed_flag`：国家队官方买入公告周标记

- 作用：标记该自然周是否存在核心国家队实体的官方买入公告。
- 公式：该周存在截至截止日可见的正式买入公告时输出 `1`；没有公告时不输出该指标，不以 `0` 表示已核验无买入。
- 证据层：`confirmed_direction`。
- 限制：只确认官方公告给出的买入方向，不改变匿名金额代理或暴露加权代理，也不据此补造买入金额。
- 版本：`state_capital_flow_v1`。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="fundamental"></a>
## 普通公司估值与财务

来源：规范化利润表、资产负债表、现金流量表、财务指标、市场价格和股本。代码位于 `src/financial_data/` 与 `src/fundamental_analysis/`。

流量字段的 TTM 桥接公式为：

`TTM = 上一完整年度 + 当前累计期 - 上年同期累计期`

年报直接使用年度值。所有记录必须满足 `published_at <= as_of_date`。`earnings` 优先使用归母净利润；自由现金流当前定义为 `经营现金流 - abs(资本开支)`。

状态机：

- `available`：公式和输入均适用。
- `missing_input`：输入缺失，不填伪值。
- `not_applicable`：分母非正、经济意义不成立或零利息等。

<a id="market-cap"></a>
### `market_cap`：总市值

- 公式：`market_price × shares_outstanding`。
- 作用：所有权益估值倍数和收益率的基础。
- 来源：截止日市场价与财务/用户覆盖股本；支持与报告市值做容差复核。
- 限制：股价和报告期股本可能不是同一时点，必须查看证据。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="enterprise-value"></a>
### `enterprise_value`：企业价值

- 公式：`market_cap + total_debt - cash_and_equivalents`。
- 作用：把股权价值扩展为核心经营资产价值。
- 当前 `total_debt`：短期借款、长期借款、应付债券和一年内到期非流动负债之和。
- 限制：当前未加入优先股、少数股东权益和投资资产调整。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="pe-ttm"></a>
### `pe_ttm`：滚动市盈率

- 公式：`market_cap / TTM earnings`。
- 作用：价格相对归母盈利的倍数。
- 限制：盈利非正时 `not_applicable`；年度快照的 `flow_basis` 为 `annual`，必须读取参数而非只看名称。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="pb"></a>
### `pb`：市净率

- 公式：`market_cap / total_equity`。
- 作用：价格相对账面权益的倍数。
- 限制：权益非正时不适用；普通公司 PB 与银行 `price/BVPS` 版本不同。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="ps-ttm"></a>
### `ps_ttm`：滚动市销率

- 公式：`market_cap / TTM revenue`。
- 作用：盈利波动或利润较低公司的一项收入估值参考。
- 限制：不反映利润率、资本强度和现金流。
- 状态：`公式已验证`、`研究性`，`fundamental_v1`。

<a id="pcf-ttm"></a>
### `pcf_ttm`：滚动市现率

- 公式：`market_cap / TTM operating_cash_flow`。
- 作用：股权价值相对经营现金流的倍数。
- 限制：经营现金流非正时不适用；受营运资本波动影响。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="ev-ebitda"></a>
### `ev_ebitda`：企业价值/息税折旧摊销前利润倍数

- 公式：`enterprise_value / EBITDA`。
- 作用：跨资本结构比较经营资产价值。
- EBITDA：优先 Provider 字段，否则 `EBIT + abs(折旧摊销)`。
- 限制：不反映资本开支和营运资本；EBITDA 非正时不适用。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="ev-fcf"></a>
### `ev_fcf`：企业价值/自由现金流倍数

- 公式：`enterprise_value / free_cash_flow`。
- 作用：企业价值相对当前简化自由现金流。
- 限制：当前 FCF 是简化口径，不等同严格 FCFF；FCF 非正时不适用。
- 状态：`公式已验证`、`研究性`，`fundamental_v1`。

<a id="earnings-yield"></a>
### `earnings_yield`：盈利收益率

- 公式：`earnings / market_cap`。
- 作用：PE 的收益率形式，可保留负盈利信息。
- 限制：允许负值；不可与债券收益率机械比较。
- 状态：`公式已验证`，`fundamental_v1`。

<a id="fcf-yield"></a>
### `fcf_yield`：自由现金流收益率

- 公式：`free_cash_flow / market_cap`。
- 作用：衡量当前股权市值对应的简化现金流收益率。
- 限制：允许负值；受资本开支周期和营运资本影响。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="dividend-yield"></a>
### `dividend_yield`：股息率

- 公式：`annual_dividends / market_cap`。
- 作用：衡量已披露年度分红相对当前市值。
- 限制：分红字段覆盖不足；历史分红不代表未来分红。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="roe"></a>
### `roe`：净资产收益率

- 公式：`TTM earnings / average(current_equity, prior_equity)`。
- 作用：衡量股东权益的会计回报。
- 限制：受杠杆、回购、一次性损益和会计政策影响；平均权益非正时不适用。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="roa"></a>
### `roa`：总资产收益率

- 公式：`TTM earnings / average(current_assets, prior_assets)`。
- 作用：衡量总资产创造净利润的效率。
- 限制：金融机构和重资产行业需使用行业口径解释。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="roic"></a>
### `roic`：投入资本回报率

- 公式：`NOPAT / average(invested_capital_current, invested_capital_prior)`。
- `NOPAT = EBIT × (1-effective_tax_rate)`；`invested_capital = equity + debt - cash`。
- 作用：衡量经营资本效率。
- 限制：亏损期有效税率可能缺失；默认税率是显式假设，不是报告事实。
- 状态：`公式已验证`、`来源受限`、`研究性`，`fundamental_v1`。

<a id="gross-margin"></a>
### `gross_margin`：毛利率

- 公式：`gross_profit / revenue`；毛利可由 `revenue-operating_cost` 派生。
- 作用：观察产品定价和直接成本结构。
- 限制：`total_operating_cost` 不等同营业成本，不用于派生毛利。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="operating-margin"></a>
### `operating_margin`：营业利润率

- 公式：`operating_profit / revenue`。
- 作用：观察主营经营利润率。
- 限制：行业分类和一次性经营项目影响可比性。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="net-margin"></a>
### `net_margin`：净利率

- 公式：`earnings / revenue`。
- 作用：观察收入转化为归母净利润的比例。
- 限制：受非经营损益、税率和资本结构影响。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="revenue-growth"></a>
### `revenue_growth`：营业收入增长率

- 公式：`current_revenue / prior_revenue - 1`。
- 作用：衡量同比收入成长。
- 限制：上期收入非正时 `not_applicable`；不代表有机增长。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="net-profit-growth"></a>
### `net_profit_growth`：净利润增长率

- 公式：`current_earnings / prior_earnings - 1`。
- 作用：衡量归母盈利同比变化。
- 限制：上期盈利非正时不输出伪增长率。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="ocf-growth"></a>
### `operating_cash_flow_growth`：经营活动现金流增长率

- 公式：`current_OCF / prior_OCF - 1`。
- 作用：观察经营现金流同比变化。
- 限制：上期 OCF 非正时不适用；受营运资本时点影响。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="fcf-growth"></a>
### `free_cash_flow_growth`：自由现金流增长率

- 公式：`current_FCF / prior_FCF - 1`。
- 作用：观察简化自由现金流同比变化。
- 限制：上期 FCF 非正时不适用；资本开支周期会放大波动。
- 状态：`公式已验证`、`研究性`，`fundamental_v1`。

<a id="debt-to-assets"></a>
### `debt_to_assets`：资产负债率

- 实际公式：`total_liabilities / total_assets`。
- 作用：表示资产负债率。
- 命名限制：这里的 debt 实际是全部负债，不是仅有息债务。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="net-debt"></a>
### `net_debt`：净负债

- 公式：`total_debt - cash_and_equivalents`。
- 作用：衡量扣除现金后的有息债务绝对额。
- 单位：货币绝对值，不是比例；负值表示净现金。
- 限制：跨公司策略阈值不能直接比较绝对额。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="interest-coverage"></a>
### `interest_coverage`：利息保障倍数

- 公式：`EBIT / abs(interest_expense)`。
- 作用：衡量经营利润覆盖利息支出的倍数。
- 输出：利息为零时 `not_applicable`；EBIT 为负时可得到负倍数。
- 限制：净利息收入公司和金融机构不适用普通公司解释。
- 状态：`公式已验证`、`来源受限`，`fundamental_v1`。

<a id="etf"></a>
## ETF 专用

代码位于 `src/fund_research/etf_metrics.py`。市场快照来自 ETF 现货价和 IOPV；费率来自人工审阅的官方费率目录。

<a id="premium-discount"></a>
### `premium_discount`：溢折价率

- 公式：`(market_price - IOPV) / IOPV`。
- 作用：正值表示溢价，负值表示折价。
- 来源：当前执行路径使用 AkShare ETF 现货字段；IOPV 必须大于零。
- 限制：点时快照可能早于任务截止日；不是历史折溢价分布。
- 状态：`公式已验证`、`来源受限`，`exchange_fund_metric_v1`。

<a id="expense-ratio"></a>
### `expense_ratio`：综合费率

- 取值：官方披露的综合费率，不是简单把管理费和托管费相加。
- 单位：年化小数比例。
- 当前覆盖：`510300` 和 `518880`；保存生效日、官方来源和 URL。
- 限制：生效日前没有历史回填，其他 ETF 会明确失败。
- 状态：`公式已验证`、`来源受限`，`exchange_fund_metric_v1`。

<a id="etf-share-flow"></a>
## ETF 份额流

来源：带统计日、原始来源和拆分调整标志的 ETF 份额记录，以及带日期、来源和估算标志的 NAV 记录，代码位于 `src/fund_research/share_flow.py`。单只 ETF 结果保存 `estimated=true`、`share_stat_date`、`nav_ref_date`、`nav_ref_source` 和 `split_adjusted`。宽基篮子可对同名、同版本因子按非负且合计为一的显式权重聚合，篮子输出绑定 `basket_id`，不绑定任何单只 ETF。

<a id="etf-share-change"></a>
### `etf_share_change`：ETF份额变化率

- 作用：衡量相邻两次可用份额统计之间 ETF 份额的相对变化。
- 公式：`(当前份额 - 前次份额) / 前次份额`。
- 来源：同一 ETF 的相邻份额记录，保留两期来源、统计日和 `split_adjusted`。
- 时间尺度：相邻份额统计日区间，不假设一定是自然日或交易日日频。
- 限制：相邻记录拆分调整标志必须一致，否则拒绝计算；份额变化不能识别申赎主体，也不证明未来收益。
- 版本：`exchange_fund_flow_v1`。
- 身份边界：单只 ETF 结果只表示产品份额变化；宽基篮子聚合后是市场篮子指标，不绑定单只 ETF，更不能称为国家队流入。
- 状态：`公式已验证`、`研究性`、`来源受限`。

<a id="estimated-net-subscription"></a>
### `estimated_net_subscription`：估算净申购额

- 作用：用份额变化和最近可用 NAV 估算相邻统计期的净申购金额。
- 公式：`(当前份额 - 前次份额) × 不晚于当前份额统计日的最近 NAV`。
- 来源：相邻 ETF 份额记录及不晚于当前份额统计日的最近 NAV；结果显式保存 NAV 日期、来源和估算标志。
- 时间尺度：相邻份额统计日区间，NAV 参考日可早于份额统计日但不得晚于它。
- 限制：这是 `estimated` 派生值，不是官方净申购额；拆分调整必须一致，NAV 时点差和份额来源会引入误差，不能包装成预测信号。
- 版本：`exchange_fund_flow_v1`。
- 身份边界：估算匿名产品申赎金额，不能确认申赎者、游资、机构或国家队；宽基篮子加权结果也不绑定单只 ETF。
- 状态：`公式已验证`、`研究性`、`来源受限`。

## 金融机构专用

代码位于 `src/fundamental_analysis/financial_institution.py`。五项字段必须来自同一完整报告期，满足披露截止日，并使用规范化单位。除 PB 外，其余四项是 Provider 报告值，不重新推导。

<a id="bank-pb"></a>
### `pb`（银行）：市净率（银行口径）

- 单位：倍数；每股净资产必须为正且单位为 `CNY_per_share`。
- 限制：与普通公司 `market_cap/total_equity` 同名但版本和输入不同。

<a id="bank-roe"></a>
### `roe`（银行）：净资产收益率（银行报告口径）

- 取值：Provider 报告 ROE，规范化为小数比例。
- 作用：衡量报告期权益回报。
- 限制：季度值可能不是年化值，不能与普通公司 TTM ROE 直接混用。
- 状态：`来源受限`，`financial_institution_v1`。

<a id="capital-adequacy"></a>
### `capital_adequacy`：资本充足率

- 取值：Provider 报告资本充足率，小数比例。
- 作用：银行资本缓冲和监管约束指标。
- 限制：当前未拆分核心一级、一级和总资本口径。
- 状态：`来源受限`，`financial_institution_v1`。

<a id="net-interest-margin"></a>
### `net_interest_margin`：净息差

- 取值：Provider 报告净息差，小数比例。
- 作用：观察生息资产利差能力。
- 限制：不同银行披露年化方式和平均资产口径可能不同。
- 状态：`来源受限`，`financial_institution_v1`。

<a id="npl-ratio"></a>
### `non_performing_loan_ratio`：不良贷款率

- 取值：Provider 报告不良贷款率，小数比例。
- 作用：观察已确认资产质量压力。
- 限制：依赖分类标准，不能替代关注类贷款、拨备覆盖和迁徙率分析。
- 状态：`来源受限`，`financial_institution_v1`。

<a id="commodity"></a>
## 周期资源

<a id="commodity-sensitivity"></a>
### `commodity_sensitivity`：大宗商品收益敏感度

- 公式：`Cov(r_asset, r_weighted_commodity) / Var(r_weighted_commodity)`。
- 商品组合收益：各显式权重商品收益之和，权重非负且总和为一。
- 对齐：所有序列当前和前一观察日必须一致；至少两个匹配收益区间。
- 作用：衡量资产收益对铜、黄金等商品组合的历史线性敏感度。
- 限制：Beta 不是因果，也不预测商品价格；权重是研究假设。
- 状态：`公式已验证`、`研究性`、`来源受限`，`commodity_sensitivity_v1`。

<a id="peer"></a>
## 同行横截面统计

代码位于 `src/peer_analysis/service.py`。统计样本只包含审核后纳入且单位、币种、报告期、计算版本一致的 peers；目标公司不进入样本。少于两个兼容 peer 时不计算分布。

<a id="peer-sample-count"></a>
### `sample_count`：有效样本数

- 含义：实际进入统计的兼容同行数量，不含目标公司。
- 状态：`公式已验证`。

<a id="peer-median"></a>
### `median`：中位数

- 公式：排序后中间值；偶数样本取两个中间值均值。
- 作用：提供对极端值较稳健的同行中心。
- 状态：`公式已验证`。

<a id="peer-mean"></a>
### `mean`：均值

- 公式：同行值算术平均。
- 限制：易受极端值影响。
- 状态：`公式已验证`。

<a id="peer-std"></a>
### `standard_deviation`：标准差

- 公式：`sqrt(sum((x-mean)^2) / N)`。
- 定义：总体标准差，不是样本标准差。
- 状态：`公式已验证`。

<a id="peer-range"></a>
### `minimum` / `maximum`：最小值/最大值

- 含义：兼容同行样本的最小值和最大值。
- 作用：显示横截面范围。
- 状态：`公式已验证`。

<a id="peer-percentile"></a>
### `target_percentile`：目标分位数

- 公式：`count(peer_value <= target_value) / N_peers`。
- 定义：左闭经验分位，不使用 mid-rank，目标本身不进入样本。
- 限制：小样本分位离散且不稳定。
- 状态：`公式已验证`、`研究性`。

<a id="peer-vs-median"></a>
### `target_vs_median`：目标相对中位数偏离

- 公式：`target / median - 1`。
- 输出条件：同行中位数不为零。
- 作用：表示目标相对典型同行的比例差。
- 状态：`公式已验证`。

<a id="strategy-dependencies"></a>
## 策略依赖索引

当前正式执行依赖：

- `quality_value`：`roe`、`roic`、`fcf_yield`、`debt_to_assets`、`pe_ttm`、`revenue_growth`。
- `etf_tracking_efficiency`：`tracking_error`、`premium_discount`、`expense_ratio`、`max_drawdown`、`excess_total_return`。
- `bank_quality_risk`：银行版 `pb`、`roe`、`capital_adequacy`、`net_interest_margin`、`non_performing_loan_ratio`，以及 `max_drawdown`。
- `resource_cycle_readiness`：`pb`、`roic`、`net_debt`、`commodity_sensitivity`、`max_drawdown`。
- `gold_etf_cycle_vehicle`：`commodity_sensitivity`、`premium_discount`、`expense_ratio`、`max_drawdown`。

已写但尚无正式执行路由：

- `trend_timing`：`momentum_5`、`return_1d`、`annualized_volatility`、`max_drawdown`、`excess_total_return`。
- `catalyst_repricing`：`pe_ttm`、`momentum_5`、`excess_total_return`、`max_drawdown`。已移除与 PE 语义冲突的金融机构和未盈利高成长 profile。
- `business_thesis_check`：财务和风险指标之外还要求商业模式、管理层等人工证据，当前不能只靠量化因子通过。

策略读取规则：

1. required metric 缺失、不可用或版本参数歧义时返回 `insufficient_data`。
2. `drawdown` 与 `max_drawdown` 不可替换。
3. 普通公司 `roe/pb` 与银行同名指标不可跨版本混合。
4. `net_debt` 是绝对金额，不能直接跨公司设统一阈值。
5. 因子通过只表示研究规则条件满足，不表示交易建议。

<a id="not-implemented"></a>
## 尚未实现

以下内容不得写成当前可计算能力：

- 通用持久化 RSI、MACD、布林带、ATR、成交量和换手率因子；当前 RSI 只在上证择时策略内计算。
- 通用指数估值分位、PEG、DCF 和多情景内在价值；当前仅实现上证市场PE四年分位的策略内计算。
- 场外基金规模指标化、场外基金综合费率、基金经理评价和持仓穿透。
- 未盈利高成长公司的 `cash_burn`。
- 行业景气、宏观利率和汇率敏感度。
- 历史 universe 成分恢复、按历史生效日重建横截面，以及真实全市场批量数据准备；不得用当前 universe 回填历史。
- 流通市值真实数据接线、稳定的历史规模分组，以及融资余额/流通市值。
- 北向公开数据正式抓取与持续接线；现有计算器不等于这些真实数据链路已经完成。
- 更大国家队 ETF 目录和更长历史回填/校准。
- 多因子回归、因子暴露显著性、因子收益和样本外预测验证。
