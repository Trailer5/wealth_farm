# 研究状态持久化模块

## 模块职责

研究状态持久化模块负责保存用户在手动研究过程中产生的长期状态，让研究流程不依赖对话记忆或临时文件。

第一阶段重点保存：

1. 自选列表和关注理由。
2. 当前持仓数量、成本和备注。
3. 用户保存的分析报告和结论。
4. 单标的用户决策简报、决策轨道和缺失上下文。
5. 与 workflow run 和 handoff 关联的探索快照及追加式账本。

## 不负责的内容

第一阶段不负责：

1. 券商级交易流水、成交回报和税费核算。
2. 复杂组合优化和收益归因。
3. 新闻、公告和研报原始数据存储。
4. 策略运行和回测。
5. Web UI。
6. 安全多租户、角色和权限。

## 目录与脚本范围

### 拥有

1. `src/research_state/`：自选、持仓、分析报告、决策简报、探索快照和追加式账本 repository。
2. `src/tests/research_state/unit_tests/`：状态读写、用户归属和查询测试。
3. `src/tests/research_state/smoke_tests/`：后续手动研究闭环验证。

### 依赖

1. `src/user_space/`：提供稳定 `user_id` 和默认用户上下文。
2. `src/master_data/`：所有自选、持仓和报告通过 `asset_id` 引用标的。
3. `src/data_store/`：共享 SQLite 数据库文件。
4. 统一数据访问模块：为手动研究提供行情和其他分析输入。
5. 自动数据获取模块：只读聚合 active 自选和非零持仓，生成去用户化跟踪候选。

### 有限覆盖

1. 用户空间模块中的默认用户和 `UserContext`。
2. 后续报告证据引用协议。

## 数据边界

共享行情、财务、公告和主数据不得复制到用户研究状态表中。

自选、持仓、分析报告、决策简报和探索会话必须包含 `user_id`。查询必须按当前用户空间过滤，避免正常使用时混淆，但当前不把该过滤作为安全授权机制。

本模块必须提供自动跟踪候选的聚合边界。该边界扫描所有用户的 active 自选和非零持仓，输出 `asset_id` 及来源类型，不输出用户身份、关注理由、标签、数量、成本或备注。

分析报告可以保存 Markdown 正文和少量 JSON 元数据。第一阶段不为报告设计复杂富文本格式。

## 初期对象

1. `watchlists`：用户的自选列表。
2. `watchlist_items`：列表中的 `asset_id`、关注理由、标签和状态。
3. `holding_positions`：用户当前持仓数量、平均成本、币种和备注。
4. `analysis_reports`：用户保存的标题、摘要、Markdown 正文、状态和标的关联。
5. `research_decision_briefs`：用户对单一标的的意图、是否/时点/仓位轨道、持仓状态、期限、组合角色、mandate/约束快照引用和缺失上下文。
6. `research_exploration_sessions`：当前探索快照、workflow run、handoff、决策简报和用户归属。
7. `research_exploration_ledger_entries`：问题、查询计划与结果、轮次、发现、假设变化和 ready 状态的不可更新追加记录。

## 输入与输出

输入包括 `UserContext`、`asset_id`、自选信息、持仓信息、分析报告内容、`ResearchDecisionBrief` 所需决策上下文和结构化探索变更。

输出包括按用户过滤的自选、当前持仓、报告、决策简报、探索快照、追加式账本及缺失用户上下文，以及供自动跟踪模块使用的去用户化标的候选集合。

## 当前能力与缺口

当前已建立 `src/research_state/`、默认自选、多个自选列表、当前持仓增删改查、Markdown 分析报告、决策简报和探索状态持久化。决策简报按 `user_id + asset_id` 更新；探索状态按用户与 workflow run 唯一关联，快照保存问题的查询历史、最近结果和查询缺口，账本通过数据库门禁保留完整计划与结果。

黄金 ETF `518880` 已跑通真实数据访问、质量门禁、自选、持仓、报告保存和重启读取。

当前缺口是跨用户自动跟踪候选聚合、公共自选边界、交易流水、持仓历史和最终报告证据。问题到公共项目能力的查询执行记录已由研究编排服务写入探索账本；workflow run 由研究编排模块拥有，本模块只保存探索侧稳定关联。InvestmentMandate 与组合约束快照由组合模块统一拥有，本模块只保存稳定引用，不复制数值风险约束。
