# IDE 单标的研究工作流模块

## 模块职责

本模块负责在 IDE 环境中把主数据、数据获取、指标、图表、行业比较、策略和证据组织成一条完整的单标的研究路径。

它不负责重复计算指标或抓取数据，而是定义研究任务如何调用各模块、如何判断数据是否足够、如何输出可复核结论。

## 研究任务入口

每次研究必须先明确：

1. 标的代码或名称。
2. 资产类型。
3. 研究问题，例如理解、比较、择时、投机、投资、论文复查或风险排查。
4. 时间尺度。
5. 数据截止日期。
6. 需要的基准、行业和可比对象。
7. 输出深度和允许的假设范围。

如果用户没有声明时间尺度，Agent 必须先根据问题推断并明确写出，不得混合多个尺度后给出单一结论。

## 标准研究流程

### 1. 身份确认

解析为稳定 `asset_id`，确认市场、交易所、资产类型、名称和 Provider 代码。身份冲突时停止后续研究。

### 2. 研究数据清单

按资产类型和研究问题列出需要的数据：

1. 行情、复权和成交。
2. 财务报表、财务指标和报告期。
3. 公告、财报原文、基金披露和研报元数据。
4. 行业、市场、指数、宏观和可比公司。
5. 事件、管理层和资本动作。

### 3. 数据获取与质量

使用统一数据访问和 Provider 获取缺失数据，记录来源、范围、单位、币种、截止日期和失败。关键数据至少使用两个独立来源或独立计算方法核验。

### 4. 基础指标与图表

计算适用于该资产类型的价格、风险、估值、质量、成长和现金流指标，生成必要图表。禁止对不适用资产机械套用指标。

### 5. 行业、市场和可比研究

解释标的相对历史、同行、行业和基准的差异。判断变化来自标的自身、行业景气还是市场 Beta。

### 6. 策略与时间尺度分析

只运行适用于当前时间尺度的策略。每个策略输出命中条件、否决条件、有效期、反证和数据缺口。

### 7. 多情景与反向检验

至少构建乐观、中性和悲观情景，并回答：

1. 市场当前可能隐含什么假设。
2. 哪些事实会证伪主要论文。
3. 永久性损失从哪里产生。
4. 最强反方观点是什么。
5. 什么情况下应停止研究或保持留白。

### 8. 综合结论

结论必须区分：

1. 已验证事实。
2. 基于事实的推断。
3. 依赖假设的情景。
4. 尚缺数据的问题。
5. 与时间尺度匹配的研究判断。

输出可以是 `通过`、`不通过` 或 `灰色地带`，但不能为了“强制结论”隐藏不确定性。

### 9. 研究产物

保存结构化摘要、指标、图表、比较结果、策略结果、证据引用、反证、数据缺口和下一步研究建议。

结构化产物分为三层：

1. Agent 层保存路由、证据等级、缺口和后续动作。
2. 开发者层保存版本、参数、数据血缘、digest、诊断和测试信息。
3. 用户层只展示结论、关键依据、影响、可选行动和观察条件。

内部版本、ID、枚举、成熟度标签、digest 和实现路径不得直接渲染到用户报告。未通过证据门槛的候选信号不进入用户结论。

## 资产类型模板

至少区分：

1. 普通公司股票。
2. 银行、保险和其他金融机构。
3. 周期与资源公司。
4. 高成长和未盈利公司。
5. ETF、LOF 和封闭式基金。
6. 场外基金。
7. 指数和行业。

每类模板必须定义必需数据、适用指标、禁用指标、基准和主要风险。

## 研究质量纪律

1. 报告顶部声明数据截止日期。
2. 关键金融数据交叉验证。
3. 精确处理币种、单位、股本和报告期。
4. 区分原始数据、计算结果和 Agent 推断。
5. 记录缺失和失败，不用猜测补齐。
6. 引用原始财报和官方公告优先。
7. 防止未来数据、幸存者偏差和选择性证据。
8. 同一模板支持半年后重新研究并比较变化。
9. 输出反方观点和论文失效条件。

## `.agent` 研究指引建设条件

只有以下能力稳定后才编写完整 Agent 研究技能：

1. 身份解析和数据获取稳定。
2. 基础指标、财务指标和图表可复用。
3. 行业、市场和同行比较可运行。
4. 策略契约、时间尺度和首批策略完成。
5. 研究产物和证据格式稳定。
6. 至少三类代表性资产完成端到端验证。

当前已在 `.agent/docs/` 建立：

1. 研究任务路由。
2. 单标的研究执行步骤。
3. 数据与指标调用手册。
4. 图表和比较输出规范。
5. 策略与时间尺度选择规则。
6. 标的发现工作流。
7. 报告模板、证据规则和复查清单。

## 当前能力与缺口

当前身份、统一数据访问、财务与 profile 专用指标、图表、行业同行与基准比较、策略、低频回测、标的发现和结构化验收报告均已有公共接口。`src/research_workflow/` 已建立研究任务契约、四类时间尺度、研究问题类型、截止日期校验和六类资产研究模板。

五个冻结任务和普通公司、ETF、金融机构、周期资源四个 profile 已通过端到端验收。`.agent` IDE 投研指引已经建立；仍需遵守数据不足停止、事实引用证据和显式记录结论限制的边界。

`ResearchExecutionService`、`ETFResearchExecutionService`、`FinancialInstitutionResearchExecutionService` 和 `CyclicalResourceResearchExecutionService` 已分别覆盖普通公司、ETF、银行和周期资源冻结路径。同行比较和叙事报告仍是独立服务，不自动塞入 profile 执行入口。
