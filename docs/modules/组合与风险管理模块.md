# 组合与风险管理模块

## 模块职责

组合与风险管理模块负责把用户当前持仓转换为组合估值，并根据显式投资任务、目标波动率、回撤约束、连续择时分位和跟踪误差计算风险预算仓位。

第一阶段把每个用户的当前持仓视为一个隐式组合，不建设多组合管理。

## 不负责的内容

第一阶段不负责：

1. 交易流水和历史持仓重建。
2. 做空、杠杆和衍生品。
3. 均值—方差收益预测优化和自动下单。
4. 压力测试和情景分析。
5. 行业、风格和因子暴露。
6. 组合历史收益率和归因。

## 目录与脚本范围

### 拥有

1. `src/portfolio_risk/`：组合估值模型、计算器、SQLite repository 和服务。
2. `src/tests/portfolio_risk/unit_tests/`：估值、权重、集中度和持久化测试。
3. `src/tests/portfolio_risk/smoke_tests/`：真实持仓估值验证。

### 依赖

1. `src/research_state/`：提供用户当前持仓。
2. 统一数据访问模块：提供最新有效价格。
3. 主数据和用户空间：提供 `asset_id`、`user_id` 和 `UserContext`。
4. `src/data_store/`：共享 SQLite 数据库。

## 第一阶段指标

1. 持仓市值：`quantity * market_price`。
2. 持仓成本：有平均成本时为 `quantity * average_cost`。
3. 持仓浮盈亏：市值减成本。
4. 持仓权重：持仓市值除以组合总市值。
5. 最大权重：所有持仓权重最大值。
6. HHI 集中度：所有权重平方和。

## 风险预算仓位

`InvestmentMandate` 保存投资目标、实际交易工具、基准、防御资产、目标波动率、最大回撤、跟踪误差、风险仓位上限和现金底线。

`PositionBudgetCalculator` 依次应用：

1. 目标波动率仓位上限。
2. 当前回撤治理。
3. 连续择时分位倾斜。
4. 相对收益任务的跟踪误差估计。
5. 现金或防御资产缓冲。

仓位由输入和约束计算，不使用固定的人工比例。目标波动率只控制风险，不预测收益；参数在历史验证前固定。

实际ETF回测显示，当前连续择时倾斜和线性回撤治理均弱于纯目标波动基线，因此两项默认关闭，只保留为实验开关。默认仓位只由目标波动率、仓位上限、现金底线及相对任务的跟踪误差检查决定。

第一阶段只支持非负持仓数量。价格缺失时明确失败，不静默忽略持仓。

## 可复现要求

每个组合快照保存用户、日期、总市值、总成本、浮盈亏、最大权重和 HHI。

每个持仓指标保存快照 ID、`asset_id`、数量、价格、市值、成本、浮盈亏和权重。

## 当前能力与缺口

当前已建立组合快照、持仓指标、市值、成本、浮盈亏、权重、最大权重、HHI、投资任务和纯函数风险预算仓位。Web 工作台仍只暴露持仓估值。

黄金 ETF `518880` 真实 smoke 已通过：100 份持仓按 8.385 估值，市值 838.5，成本 810，浮盈 28.5，快照可以重新读取。

当前缺口是投资任务持久化、连续仓位回测、实际ETF工具选择、组合历史收益、压力测试以及行业与风格暴露。
