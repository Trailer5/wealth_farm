# 研究可视化模块

## 模块职责

本模块负责把行情、风险、估值和财务序列转换为 IDE 可读取的静态研究图表，并同时保存同源数据和 metadata。

## 目录范围

1. `src/research_visualization/`：图表模型、builder 和 Matplotlib renderer。
2. `src/tests/research_visualization/unit_tests/`：产物、截止日期和字段测试。
3. `src/tests/research_visualization/smoke_tests/`：真实研究图表验证。
4. `report/`：用户报告、图表、同源数据和审计 metadata。

## 当前图表类型

1. `price_volume`
2. `cumulative_return`
3. `drawdown`
4. `rolling_risk`
5. `valuation_history`
6. `financial_trends`

## 产物契约

每张图生成：

1. PNG。
2. SVG。
3. 同源 `.data.json`。
4. `.metadata.json`。

metadata 包含任务、标的、截止日期、单位、币种、复权方式、基准、来源 dataset、参数、版本、点数和输入摘要哈希。

## 输出边界

临时研究默认写入：

```text
temp/research/<task_id>/charts/
```

`temp/` 已被 Git 忽略。用户报告通过 `ReportArtifactService` 发布到：

```text
report/<报告文件>.md
report/assets/<report-slug>-<chart-key>/charts/
```

Markdown 使用相对路径引用 PNG；SVG、同源数据和 metadata 保留在同一报告资产目录。内部版本和摘要只写 metadata，不渲染到用户正文。

## 当前能力

1. 六类图表均可通过 Python API 生成。
2. 相同 `ChartSpec` 产生相同文件名和 metadata。
3. 图表数据严格过滤到 `as_of_date`。
4. PNG、SVG 和 JSON 使用同一数据对象。
5. 普通公司、ETF 和场外基金选择不同图表集合。
6. Windows 中文字体回退已配置。
7. `ReportArtifactService` 统一报告路径、图表发布和相对引用。
8. 上证指数报告已生成K线、成交量、均线、PE历史、PE滚动分位和股权风险溢价图。
9. 标准单标的编排可把执行阶段已有图表发布为稳定的 `chart.png`、`chart.svg`、`data.json` 和 `metadata.json`，并自动嵌入用户 Markdown。
10. 因子序列图标题和 metadata 显式保存实际输入起止日期，不以研究期限名称替代真实覆盖。
11. 场外基金复合基准可用时，累计收益图使用共同观察日叠加基金与官方基准序列，并保存复合基准 ID 和双方来源；基准不可用时保持单基金序列。
12. 最终决策报告可直接引用基础包已经发布在 `report/assets/` 下的相对静态图片；最终发布门禁会检查文件真实存在，不重复渲染或把内部 metadata 复制进正文。

真实 smoke 已生成黄金 ETF 价格/收益/回撤图、贵州茅台估值和财务趋势图；002236 累计收益图已叠加官方 95% 指数 + 5% 现金复合基准，metadata 记录 2016-08-25 至 2026-08-21 共 2425 个共同观察点。

## 计划 HTML

`src/research_visualization/plan_html.py` 把组合计划的结构化载荷（`portfolio-plan` 生成的计划、节点、标签、调整前后概况）渲染成一个离线 HTML 文件，写在 `report/` 下与计划 Markdown 同名。

1. **离线。** 只用内联 CSS、内联 SVG 和一段筛选脚本，不引用任何外部资源，断网可开。
2. **内容。** 要点；时间轴（按标的分行，实心条是定期节点、虚线框是条件节点、绿色买入、红色卖出、菱形是复盘）；可按标的和条件节点筛选的节点表；目标区间、概率与依据；复盘节点与改进方法；冲突处理与被排除的动作；看板（权益、波动、最大个股与行业的调整前后对比，大类、行业、风险贡献、历史情景的成对条形图，偏好对照与一年收益区间）；数据缺口与局限。
3. **同源与复查。** 页面内嵌渲染所用的计划 JSON。`check_plan_html` 比对页面与计划：内嵌计划是否相同、节点表的动作编号是否与计划动作一一对应、每个复盘日、目标区间、冲突与排除说明是否都在页面上。计划服务写完页面后读回比对，不一致就删掉页面并在输出里列出问题。
4. **安全。** 所有文本经 HTML 转义；内嵌 JSON 中的 `<` 写成 `\u003c`，用户文字不会变成标签或脚本。

## 不负责的内容

1. 在线 Web 交互图（计划 HTML 只有本地筛选）。
2. 实时刷新。
3. 图表画线和缩放。
4. 同行散点和行业比较。
5. 自动撰写用户结论。

## 当前缺口

1. 同行比较图。
2. 多期真实估值和财务历史产物。
3. 更多市场级指标 builder。
