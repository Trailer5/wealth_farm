# 标的发现模块

## 模块职责

标的发现是特殊的策略流程。它不从用户自选出发，而是在合适的市场、行业、事件和估值条件出现时，从更大的候选集合中发现值得深入研究的标的。

发现结果不是买入结论。每个候选必须重新进入单标的完整研究流程。

## 发现时机

1. 市场或行业大幅回撤。
2. 估值进入历史极端区间。
3. 盈利、现金流或资本效率发生拐点。
4. 行业供需、政策、技术或竞争格局变化。
5. 重大事件造成价格与基本面脱节。
6. 相对强弱、成交量或资金行为异常。
7. 高质量公司进入合理价格。
8. 产业链出现真实瓶颈或利润池迁移。

## 发现策略

1. 质量筛选：先排除财务质量、治理和持续经营风险。
2. 估值筛选：历史分位、同行分位、自由现金流收益率和资产价值。
3. 成长与拐点：收入、利润、订单、产能、库存和现金流变化。
4. 行业漏斗：全市场到行业候选，再到少数深度研究标的。
5. 事件筛选：财报、回购、分红、管理层、监管和重大合同。
6. 技术状态：只用于识别研究时机，不直接代替基本面判断。
7. 产业链瓶颈：验证瓶颈持续性、扩产周期、替代难度和估值。
8. 反共识：寻找市场预期与可验证事实的偏差。

## 时间尺度

1. 短期发现：异动、事件和技术状态，服务择时研究。
2. 中短期发现：催化剂、预期差和景气拐点，服务投机性研究。
3. 中长期发现：质量、成长、竞争格局和估值错配，服务投资研究。
4. 长期发现：结构趋势、产业周期、护城河和资本配置，服务周期阅读。

发现策略必须声明时间尺度。短期异动候选不得直接进入长期推荐清单。

## 候选漏斗

1. 定义研究宇宙和数据截止日期。
2. 执行硬性排除条件。
3. 生成初筛候选并保存命中原因。
4. 使用行业、基准和同行数据复筛。
5. 评估估值、质量、风险和催化剂。
6. 输出少量候选、淘汰理由和数据缺口。
7. 对候选执行完整单标的研究。

## 目录范围

1. `src/security_discovery/`：拥有发现规格、三层漏斗、已存指标装配和 SQLite 运行记录。
2. `src/tests/security_discovery/unit_tests/`：覆盖确定性、数据缺失、淘汰原因、候选多样性、任务草稿和持久化。
3. `src/tests/security_discovery/smoke_tests/`：使用真实沪深 300 当前 universe 和 6 个固定指标样本验证结构；不代表 300 个成员均完成真实指标筛选。
4. `src/research_universe/`：依赖；提供带版本和有效日期的候选集合。
5. `src/fundamental_analysis/`、`src/factor_engineering/`：依赖；提供已计算的质量、估值、风险和相对表现指标。
6. `src/research_workflow/`：依赖；提供时间尺度和 `ResearchTaskSpec`。
7. `src/event_name_discovery/`：拥有外部重大事件与证券名称注意力外溢的专项发现流程。
8. `src/backtest/event_name_event_study.py`：按事件族留出并隔离重叠窗口的发现效果研究。

## 当前漏斗契约

首版 `quality_value_relative_funnel` 只支持普通公司中长期研究，使用八项必需指标：ROE、ROIC、资产负债率、PE TTM、自由现金流收益率、超额收益、最大回撤和年化波动率。

1. 第一层检查身份、资产状态、研究 profile 和全部必需指标覆盖；缺失进入 `insufficient_data`，不能记作淘汰。
2. 第二层执行盈利、杠杆、估值、现金流和相对表现硬性条件，并保存命中条件、失败条件、观测值和原因。
3. 第三层分别建立财务确定性、估值弹性和风险韧性轨道，以轨道轮转和单轨上限保持候选维度多样性，不汇总为总分机械选择前三。
4. 每个候选生成确定性 `ResearchTaskSpec` 草稿，可以直接恢复并进入单标的中长期投资研究。

SQLite schema version 22 保存完整 `DiscoveryRun`，同时为 universe 每个成员保存独立结果。相同规格、universe 版本和指标输入生成相同 run ID、候选和任务草稿 ID。

## 防偏差要求

1. 保存所有淘汰理由，避免只展示幸存者。
2. 避免市值、热门叙事、英文资料和当前上市状态偏好。
3. 使用历史时点可得数据，防止未来信息泄漏。
4. 记录数据覆盖不足，资料少不等于公司差。
5. 发现频率和阈值必须回测，避免每天产生大量无效候选。

## 当前能力与缺口

当前已有首个版本化研究宇宙和质量—估值—相对表现漏斗。运行会保存候选、通过未选、淘汰、数据不足、未解析和非活跃状态及其理由。

2026-08-03 smoke 在真实沪深 300 当前 universe 的 300 个成员上完成全成员状态验证：使用 6 个确定性固定指标样本得到 3 个候选、1 个淘汰、1 个通过未选和 295 个数据不足结果。固定指标只验证漏斗结构，不是实际财务证据或投资结论。

新增全成员 profile 分类：300 条行业记录全部匹配，得到 221 个普通公司、51 个金融机构和 28 个周期资源。普通公司默认分类为中等置信度，不能识别高成长未盈利。

分类后真实准备 smoke 远程尝试 5 个普通公司，4 个指标完整；其中 2 个进入候选、2 个被硬条件淘汰。剩余 217 个普通公司待分批续跑，79 个非普通公司不进入当前漏斗，未使用 fixture。

schema 24 批处理 job 已验证暂停续跑：两个批次各限制 2 次远程尝试，最终 3 个 ready、1 个 exhausted、217 个 pending、79 个 unsupported profile。job 不自动循环，由用户手动继续。

已新增 `event_name_attention_discovery_v1`：接受带来源的人工确认外部事件，使用时点名称、汉字/拼音匹配、四类经济关系检查和市场异常反应生成短期探索候选。它与 `quality_value_relative_funnel` 分离，不把结构化事件硬塞入基本面指标漏斗。

事件名称发现会保存全体状态、生成探索会话，并能按事件族执行面板研究；当前尚未导入真实历史事件样本，也不自动从全网新闻判断重大事件。完整沪深 300 普通公司扫描仍需继续分批准备剩余指标，不会无限制触发远程请求。

本模块应在基础指标、行业比较和策略契约完成后建设，并最终作为 IDE Agent 研究入口之一。
