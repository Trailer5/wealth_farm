# 代表性研究验收模块

## 模块职责

本模块使用冻结的 `ResearchTaskSpec` 检查不同研究 profile 能否通过公开服务完成数据、指标、图表、比较、策略、证据和报告链路。

它只装配和评价现有能力，不新增指标、策略或投资结论。

## 目录范围

1. `src/research_acceptance/`：拥有冻结任务、验收步骤、声明类型、情景、缺口、单标的报告和跨标的准入结论。
2. `src/tests/research_acceptance/unit_tests/`：覆盖序列化、结构重放、状态判定和不同 profile 去重。
3. `src/tests/research_acceptance/smoke_tests/`：通过公开服务运行五个冻结任务。
4. 其他研究模块：依赖；验收模块读取其公开输出，不直接查询内部 SQLite 表。

## 固定契约

每份报告必须包含以下七步：

1. 研究任务。
2. 数据与质量。
3. 指标及版本。
4. 图表及输入摘要。
5. 基准、行业或同行比较。
6. 与任务时间尺度匹配的策略。
7. 研究证据。

报告还必须包含乐观、基准和悲观三情景、最强反方、失效条件、带类型的结论和明确缺口。结论类型分为事实、推断、假设、未知和不适用；事实必须附证据引用。

## 状态规则

1. `complete`：所有适用步骤成功执行，且没有缺口或未知结论。策略步骤成功表示得到可解释的非 `insufficient_data` 结果；策略结果本身可以是 pass、fail 或 vetoed，不能据此改变研究链路完成状态。
2. `partial`：链路可运行，但存在非阻塞缺口或未知结论。
3. `blocked`：缺少 profile 必需指标、匹配策略、关键数据集，或运行步骤失败。
4. `not_applicable` 不能伪装成 `pass`，也不能用其他 profile 指标替代。

## 重放与准入

验收报告 ID 和结构摘要由冻结任务与步骤结构确定。任务先经过 `ResearchTaskSpec` 序列化恢复，再比较结构摘要。

Agent 研究指引准入要求至少三个不同研究 profile 完整通过。多个标的共享同一 profile 时只计一次。

当前 `plan15_v1` 的详细结果位于 `docs/代表性标的研究验收报告-plan15_v1.md`。五个冻结任务在联网 smoke 中完成，但该 smoke 仍是测试编排，不等同于正式研究执行服务。

复核后已新增四类正式执行服务和 `ResearchReportAssemblyService`。普通公司真实 smoke 已从正式执行结果生成七步、三情景、反方、失效条件和可重放 complete 报告；Plan15 smoke 仍保留为跨 profile 回归入口。
