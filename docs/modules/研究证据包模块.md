# 研究证据包模块

## 模块职责

本模块负责把按标的查询的官方公告、第三方研报元数据、文档文本状态和结构化事件组装为可追溯研究证据包。

## 目录范围

1. `src/research_evidence/`：证据模型、文档状态和 bundle service。
2. `src/tests/research_evidence/unit_tests/`：证据层级、截止日期、事件幂等和文档状态测试。
3. `src/tests/research_evidence/smoke_tests/`：真实公告和研报证据验证。

## 当前 datasets

1. `disclosures`
2. `research_reports`

## 证据层级

1. `official`：官方公告和官方文档文本。
2. `third_party`：第三方研报元数据。
3. `derived`：从来源记录提取的结构化事件。

研报观点不得作为官方事实。事件必须保留来源记录和规则版本。

## 文档状态

1. `not_downloaded`
2. `download_failed`
3. `downloaded_no_text`
4. `text_available`
5. `extraction_failed`

PDF 状态不影响公告元数据本身的可用性。文本证据必须保留 document ID、提取器、页数和截断状态。

## 当前能力

1. 公告和研报元数据接入统一数据访问。
2. 按 `asset_id`、日期和 `as_of_date` 查询。
3. CNINFO/SSE/SZSE/BSE 和东方财富 Provider 路由。
4. 本地缓存、远程补取、空结果 coverage 和旧数据回退。
5. 按代码查询公告直接关联标的。
6. 公告自动进入 `EventKnowledgeService`，重复运行幂等。
7. 文档全文片段和财务字段数量进入证据包。
8. `ResearchEvidenceBundle` 区分来源层级、错误和完整性。

贵州茅台真实 smoke 已返回 30 条 CNINFO 公告、100 条研报元数据和 9 个结构化事件。

## 不负责的内容

1. 通用新闻。
2. 模糊信息与标的关系判断。
3. AI 分类。
4. 研报 PDF 反爬。
5. Web 信息流。

## 当前缺口

1. 更多来源交叉核验。
2. PDF 正文的真实批量验证。
3. 文档片段页码级引用。
4. 财务规范化数据与 PDF 字段的合并。
