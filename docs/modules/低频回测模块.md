# 低频回测模块

## 模块职责

本模块负责用历史日频数据模拟研究规则的次日执行结果，保存交易、净值、成本、基准和绩效，用于验证策略假设而不是承诺未来收益。

## 目录范围

1. `src/backtest/`：模型、日频引擎和 SQLite repository。
2. `src/tests/backtest/unit_tests/`：时间、成交、成本和持久化测试。
3. `src/tests/backtest/smoke_tests/`：真实策略回测演示。

## 当前边界

1. 日频。
2. 单策略。
3. 单标的或固定小集合。
4. 只做多，不使用杠杆。
5. 信号至少延迟一个交易日。
6. 次日开盘执行。
7. 允许小数份额，仅用于研究模拟。

## 成交规则

1. 买入价格加入正向滑点。
2. 卖出价格扣除滑点。
3. 买卖均收手续费。
4. 停牌不可成交。
5. 涨停不能买，跌停不能卖。
6. 不可成交订单延期。
7. 新信号可以替代旧挂单，并保存替代原因。
8. 过期信号不执行。

## 当前输出

1. 逐笔交易。
2. 每日现金、数量和净值。
3. 跳过订单及原因。
4. 总收益和年化收益。
5. 波动率、最大回撤和 Sharpe。
6. 基准收益和超额收益。
7. 换手、手续费和滑点成本。
8. 样本内、样本外和全样本标签。
9. 连续信号五档分层、相关性和时间分段稳定性。
10. 移动块重采样区间，用于处理时间序列相关性。

## 可复现要求

每笔交易必须关联策略信号日期和实际成交日期。回测规格保存策略版本、费用、滑点、无风险利率、复权口径、基准和时间区间。

`SQLiteBacktestRepository` 保存运行、交易、净值和跳过订单，可无损恢复。

## 当前真实结果

黄金 ETF `trend_timing_v1` 在 2026-07-01 至 2026-07-24 的短窗口演示中：

1. 全样本收益约 -0.50%，Sharpe 约 -0.77。
2. 样本内收益约 -0.69%。
3. 样本外收益约 +0.19%。
4. 费用和滑点均已扣除。

该窗口过短，结果只证明引擎可运行，不证明策略有效。`trend_timing_v1` 继续保持 `research_rule`。

## 不负责的内容

1. 参数搜索。
2. 多策略组合。
3. 组合优化。
4. 做空和杠杆。
5. 分钟和实时交易。

## 当前缺口

1. 历史复权和公司行为完整验证。
2. 更长样本和滚动样本外。
3. 历史指数成分。
4. 多标的组合回测。
5. 参数稳定性和多重检验。
6. 跨指数面板和严格扩展窗口样本外。
