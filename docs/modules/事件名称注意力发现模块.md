# 事件名称注意力发现模块

## 职责

本模块发现重大外部事件发生后，因为证券名称、谐音或组合短语产生注意力外溢，但与事件不存在真实经济关系的 A 股研究线索。

结果只表示值得继续核验的行为异象，不是买入、卖出或做空指令。

## 目录范围

1. `src/event_name_discovery/`：外部事件、名称历史快照、语言匹配、经济关系证据、市场反应、候选分轨和 SQLite 运行记录。
2. `src/research_orchestration/event_name_discovery.py`：公共编排入口和探索会话交接。
3. `src/backtest/event_name_event_study.py`：跨事件面板、事件族留出和重叠事件隔离。
4. `src/tests/event_name_discovery/unit_tests/`：语言、关系、时点、市场反应、候选状态和持久化测试。
5. `docs/evidence/strategy_sources/event_name_attention_discovery.md`：论文、公开实现和反证登记。

## 发现链路

1. `ExternalEventAnchor` 保存事件首次公开时间、时区、来源和人工确认短语。
2. `EventShockAssessment` 要求单一时间、突发或决定性结果、全球与中国大众关注、直观方向和唯一叙事同时成立；长期议题或泛地区名称不能进入扫描。
3. `AssetNameSnapshot` 只使用事件时点有效的正式简称和审阅别名。
4. `EventNameMatcher` 按直接包含、组合片段、拼音距离和显式拼音首字母生成可解释候选；支持中文名称与英文热门缩写的跨语言碰撞，不产生加权总分。
5. `ConsensusFormationAssessment` 检查事件显著性、叙事简单性、协调焦点、价格弹性、传播反馈、套利约束和市场风险偏好；不推断统一主力或违法操纵。
6. `BusinessRelationAssessment` 检查主营、股权、商业联系和公告联系。四项均有反证才允许 `confirmed_unrelated`；缺一项进入证据不足。
7. `AlternativeCatalystAssessment` 检查公司公告、行业主题、公司行动和市场叙事；存在同期更直接催化时标记为污染样本。
8. `AttentionAttributionAssessment` 处理IPO等直接催化与名称叙事并存的混合样本；只有具备同类比较时才允许研究增量叙事，不能把全部涨幅归因于名称。
9. `EventMarketReactionCalculator` 将盘前、盘中、盘后和非交易日事件映射到交易日，计算市场调整异常收益、成交量标准分和后续反转。
10. 默认以异常价格或异常成交任一渠道确认注意力反应；研究规格可以切换为价格与成交同时确认。
11. `EventNameDiscoveryService` 保存全部未匹配、真实相关、共识不足、替代催化、混合归因、反应不足、方向冲突、时点模糊和候选上限结果。
12. 候选分为 `positive_attention_echo`、`negative_mistaken_selloff`、`mixed_catalyst_attention_overlay` 和 `reversal_watch`，然后生成短期或中短期 `ResearchTaskSpec`。
13. 编排器为每个候选创建名称注意力、经济无关、共识协调、替代催化、名称增量归因和临时价格压力探索假设。

## 时点纪律

1. 外部事件必须带时区和首次公开时间。
2. 事件交易日由显式交易所日历确定；股票停牌或缺数不能被误当成下一个交易日。
3. 每份市场反应保存事件 ID、首次公开时间、日历 ID 和计算版本，预计算结果不能绑定到另一事件。
4. 盘中事件使用日线时标记为 `intraday_ambiguous`，不进入候选或事件研究。
5. 历史扫描按事件日加载名称；有有效名称历史的退市标的仍进入扫描，当前存续状态不得造成幸存者偏差。
6. 当前展示名只有显式 opt-in 才可用于当前扫描，不能回填历史。
7. `knowledge_cutoff_at` 与结果观察截止日分开；关系、替代催化评估及其每条证据必须早于知识截止时间。
8. 反转值只有观察截止日晚于事件交易日时才允许保存。

## 研究验证

`EventNameEventStudyEngine` 分析所有已确认无经济关系、替代催化覆盖完整且具有市场反应的语言匹配，包括没有达到候选阈值的样本，避免只研究幸存候选。

正式验证必须提供冻结时间早于发现运行的 manifest，明确训练/留出事件 ID、匹配器版本和发现规则 digest。验证按事件而非股票等权，链式重叠事件使用跨资产事件簇隔离。回顾性短语不得进入留出结果。样本不足时不输出显著性结论，也不把结果称为可执行 PnL。

品牌与产品不强行进入证券候选。`NameAssociationCaseAssessment` 分别保存搜索注意力、情绪、购买意向、实际销售和证券价格证据，防止把低层注意力变化包装成经济损失。

## 依赖

中文拼音转换使用审阅过的 MIT 许可 `pypinyin`。当前环境安装命令：

```powershell
python -m pip install pypinyin
```

拼音依赖缺失时，直接包含和组合短语仍可运行；拼音匹配不会用自造映射静默填补。

## 当前边界

1. 首版重大事件由用户或 Agent 确认并提供来源，不自动判断全网新闻的重要性。
2. 业务无关需要结构化证据或探索阶段人工复核，不把“未搜索到”写成“确认无关”。
3. 正向名称炒作可能直接涨停且 A 股做空受限，主要用于风险提示和反转观察。
4. 负向误杀可以生成中短期做多研究任务，但仍需完整单标的研究。
5. 具体案例、样本数量和预测验证结论属于用户研究报告，不在模块文档中维护。
