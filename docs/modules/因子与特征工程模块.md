# 因子与特征工程模块

## 模块职责

因子与特征工程模块负责把行情、财务、事件和组合数据转换为可复用、可版本化的特征，供手动研究、策略、回测、报告和 AI 分析共同使用。

第一阶段只实现基础日线行情因子。

## 不负责的内容

第一阶段不负责：

1. 选股策略和买卖信号。
2. 回测、参数搜索和组合优化。
3. 机器学习特征平台。
4. 实时和分钟级因子。
5. 复杂技术形态识别。
6. 基本面和事件因子。

## 目录与脚本范围

### 拥有

1. `src/factor_engineering/`：因子模型、计算器、SQLite repository 和查询服务。
2. `src/tests/factor_engineering/unit_tests/`：计算、版本和持久化测试。
3. `src/tests/factor_engineering/smoke_tests/`：真实行情因子验证。

### 依赖

1. 统一数据访问模块：提供按交易日排序的日线记录。
2. 主数据模块：通过 `asset_id` 关联标的。
3. 数据质量模块：保证输入达到最低可用要求。
4. `src/data_store/`：共享 SQLite 数据库。

## 首批因子

1. `return_1d`：最近两个交易日收盘价收益率。
2. `sma_5`：最近 5 个交易日收盘价均值。
3. `momentum_5`：最新收盘价相对 5 个交易日前收盘价的变化率。
4. `volatility_5`：最近 5 个日收益率的年化总体标准差。
5. `drawdown`：最新收盘价相对输入窗口最高收盘价的回撤。

数据不足的因子不生成值，也不填充伪结果。

## 可复现要求

每个因子值必须保存：

1. `asset_id`。
2. 因子名称。
3. `as_of_date`。
4. 数值。
5. 计算版本。
6. 参数。
7. 输入起止日期。
8. 来源数据集。

相同标的、因子、日期、版本和参数必须幂等写入。

## 当前能力与缺口

当前已建立 `src/factor_engineering/`、五个基础行情因子、`factor_values` schema、计算版本、幂等写入和查询服务。Web 标的研究页可以在统一日线通过质量门禁后显式重算并刷新因子。

黄金 ETF `518880` 真实 smoke 已通过：18 条日线生成并保存 5 个因子，质量门禁通过。

当前缺口是基本面、事件、组合因子，以及策略使用和因子历史批量计算。
