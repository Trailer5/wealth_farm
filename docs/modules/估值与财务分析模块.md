# 估值与财务分析模块

## 模块职责

本模块负责把规范化财务数据、股价和股本组装为可解释 TTM 财务快照，并使用精确十进制计算普通公司的估值、盈利质量、成长、现金流和杠杆指标。

## 目录范围

1. `src/fundamental_analysis/`：快照、计算器、精确结果 repository 和 service。
2. `src/tests/fundamental_analysis/unit_tests/`：公式、适用性、证据和持久化测试。
3. `src/tests/fundamental_analysis/smoke_tests/`：真实公司指标验证。

## 当前指标

1. 市值和企业价值。
2. PE、PB、PS、PCF。
3. EV/EBITDA、EV/FCF。
4. Earnings Yield、FCF Yield、股息率。
5. ROE、ROA、ROIC。
6. 毛利率、营业利润率和净利率。
7. 收入、利润、经营现金流和自由现金流增长。
8. 资产负债率、净负债和利息保障倍数。

## 计算纪律

1. 使用 `Decimal` 计算和文本精确落库。
2. 指标保存公式、分子、分母、单位和输入证据。
3. 市值使用股价乘总股本，并支持与报告市值做容差复核。
4. 中期报表通过“上年年度 + 当期累计 - 上年同期累计”形成 TTM。
5. ROE、ROA 和 ROIC 使用期初期末平均余额。
6. 负盈利、负权益和零利息等情况返回不适用状态。
7. 缺失输入返回缺失状态，不填充伪值。

## 当前能力

1. `FundamentalSnapshotAssembler` 组装当前和上年 TTM/余额。
2. `FundamentalMetricCalculator` 计算 24 类结果。
3. `SQLiteFundamentalMetricRepository` 保存可用和不可用结果。
4. `FundamentalAnalysisService` 只允许普通公司模板。
5. 英文和中文 Provider 字段映射包含主要利润表、资产负债表和现金流字段。

当前暂定计算版本为 `fundamental_v1`，披露截止日期守卫已下沉到装配器，EV 和收益率指标保留完整市值证据链。贵州茅台真实 2026Q1 快照已计算 PE 约 19.64、PB 约 6.00、PS 约 9.27、ROE 约 31.26%、ROIC 约 40.02%。股息率和 EV/EBITDA 因来源字段不足明确标记为不可用。

## 不负责的内容

1. 银行和保险专用指标。
2. ETF 和基金指标。
3. DCF。
4. 同行分位。
5. 综合评分。

## 当前缺口

1. 股息和 EBITDA 更多来源映射。
2. 银行、保险和未盈利公司模板。
3. 历史批量快照。
4. 同行和历史估值分位。
5. 图表输出。
