# 宏观数据模块

系统模块：D7 全市场截面与宏观数据（宏观部分），数据层。截面面板、历史指数成分和退市标的仍是规划。

## 职责

1. 维护宏观与利率序列目录（`src/macro_data/catalog.py`）：序列 ID、中文名、类别（增长、通胀、流动性、信用、利率）、频率、单位、来源优先级和发布日规则。
2. 同时调用目录中的全部来源（`src.data_src.fan_out`，每个来源在独立子进程中限时运行），保存每个来源的原始观测值，再按优先级合并。
3. 按截止日给出时点一致的值：只返回 `available_at` 不晚于截止日的观测。

不负责：宏观状态判断与档案（W4、R4）、观点检验与结算（R5 经 `macro:<series_id>` 读取本模块）。

## 数据与口径

| 字段 | 含义 |
| --- | --- |
| `period` | 月度 `YYYY-MM`，季度 `YYYY-Qn`（GDP 为累计口径，Q3 表示前三季度），日度或事件 `YYYY-MM-DD` |
| `available_at` | 来源写明发布日期时用发布日期（`available_at_basis = published`）；否则按目录规则保守推定（`inferred_conservative`），推定日晚于官方惯常发布日，回测不会提前看到数据 |
| `confirmed_by` | 数值一致的其他来源 |
| `conflicts` | 同一期不同来源数值不一致（百分比差超过 0.05，金额差超过 0.5%）；取优先来源的值 |

推定规则：CPI、PPI 次月 15 日；PMI 次月 1 日；M1、M2、新增贷款、社融次月 20 日；GDP 季后次月 25 日；LPR、Shibor、国债收益率为观测当日。

## 入口

- 服务：`container.macro_data`（`MacroDataService`）：`catalog()`；`get(series_id, start_date, end_date, as_of_date=None, allow_remote=True, max_age_seconds=86400)` 返回 `MacroSeriesResult`（`points`、`latest`、`successful_sources`、`provider_errors`、`conflicts`、`stale`、`last_fetched_at`）。
- CLI：`python -m src.research_orchestration.cli macro` 列出目录；`macro --series cpi_yoy [--start-date] [--end-date] [--as-of-date] [--limit 24] [--no-remote]` 输出 JSON。
- 存储：`macro_observations`（每个来源一行）与 `macro_fetch_log`（每次取数的来源、范围、条数和错误）。同一区间一天内取过数则直接读库。各来源在自己的线程里写库与记日志，超过 10 秒宽限才返回的来源本次报 `SourceStillRunning`，结果仍会入库，下次合并时参与交叉核对。

## 当前缺口

1. 东方财富系月度数据没有发布日期，只能推定；只有 CPI 的最新一期能从统计局发布页取到真实发布日。统计局数据查询接口（easyquery）当前被 WAF 拒绝。
2. 社融来源滞后，需要第二来源（人民银行官网只有 Excel 下载）。
3. 尚未进入单标的探索查询路由；Q1、Q7 的配方与档案在切片三、四、六接入。
4. 海外宏观（FRED、世界银行）可通过 `curl_cffi` 访问，尚未接入。
