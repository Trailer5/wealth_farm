# 行业分类数据模块

系统模块：D7 全市场截面与宏观数据（行业分类部分），数据层。代码在 `src/sector_data/`。

## 职责

1. 维护申万 2021 一、二、三级行业目录（代码、名称、层级、上级、成分数）。
2. 维护股票到申万三级行业的当前成分映射（含纳入日期），由此得到任一股票的一、二、三级行业。
3. 给出默认同行：同一三级行业的其他成分；不足 5 个时改用二级行业。
4. 把申万行业指数登记为主数据中的指数（`exchange = sw`），行情经统一访问读取（来源 `sw`：AkShare `index_hist_sw`，1999 年起）。
5. 按需采样行业估值历史：月末与最新交易日的 PE、PB、股息率、成交额占比、换手率和流通市值。

不负责：行业状态判断与档案（W5、R4，阶段 6 切片四）；同行指标比较（T3 `peer_analysis`）；按时点追溯的行业变更。

## 口径与时点

| 项 | 口径 |
| --- | --- |
| 目录 | AkShare `sw_index_first_info`、`sw_index_second_info`、`sw_index_third_info`（31/131/335 个）；按名称链接上级 |
| 成分 | AkShare `index_component_sw` 逐个三级行业取当前成分；只有当前成分及纳入日期，历史上的行业变更不追溯，回溯使用时须标注 |
| 指数行情 | 申万行业指数为价格指数，不含分红；源数据成交量单位为亿股、成交额为亿元，入库前换算为股和元 |
| 估值 | AkShare `index_analysis_daily_sw`：一级行业 2010 年前已有；二级行业来源在 2021-12 申万行业调整前使用旧代码，新代码历史较短；三级行业没有估值来源 |
| 采样 | 交易日取自该行业指数日线，每月最后一个交易日加最新交易日；每个日期整级取一次并缓存，之后只取缺的日期 |
| 刷新 | 目录与成分超过 30 天自动重取；成分刷新有失败的行业时保留旧的完整映射 |

## 入口

- 服务：`container.sector_data`（`SectorDataService`）：`industries(level, parent_code)`、`industry(code)`、`classify(symbol)`、`members(code)`、`peers(symbol, min_peers=5)`、`index_asset(code)`、`valuation_history(code, start_date, end_date)`。
- CLI：`python -m src.research_orchestration.cli industry [--level 1|2|3] [--parent <code>]` 列出行业；`industry --symbol <股票代码>` 给出一、二、三级行业、各级行业指数的 `asset_id` 和默认同行；`industry --code <行业代码> [--members] [--valuation --start-date <日期>]` 给出行业、子行业、指数 `asset_id`、成分和估值采样（默认近 10 年）。
- 探索查询：单标的探索的 `industry_analysis` 查询在没有行业归属时自动按申万三级行业归属，并保存默认同行集合（`peer_set_id`）。
- 存储：`sw_industries`、`sw_industry_members`、`sw_industry_valuations`、`sector_fetch_log`（schema 38）。

## 当前缺口

1. 没有历史行业成分；申万官网历史分类文件当前证书校验失败。
2. 三级行业没有估值历史；需要时用所属二级行业或成分股估值（阶段 6 切片三）。
3. 主题（概念）不建成分，由 Agent 映射为申万行业组合并写明依据。
