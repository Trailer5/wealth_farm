# 研究范例：民主党赢得中期选举与黄仁勋离任（2026-11-15）

状态：第一次完整实践的正向范例。用户评价：几乎完整走过了从重要市场消息、各自提出观点、用事实与数据反驳、立住判断、外推剪枝出机会领域、选股、数据研究到最终计划的全部步骤。

## 一、为什么是范例

1. **链条完整。** 消息 → 各方观点 → 事实与数据驳斥 → 立住或修正 → 沿产业链外推并剪枝 → 选股与数据研究 → 决策（是否、何时、多少）→ 验证节点 → 例行跟踪。
2. **确立了研究范式。** 事实会在分钟到一日内被市场消化，知道事实时已经滞后；价值来自充分基于信息、事实与专业知识的前瞻判断。观点互相驳斥而不折中，驳不倒的推论作为阶段共识外推到计划，再由验证节点修正或推翻。范式沉淀为流程 `.agent/docs/research/playbooks/debate.md` 和命令 `debate`，见 `docs/modules/5-研究产物/观点辩论模块.md`。
3. **能力缺口当场补成项目能力**，而不是临时脚本拼凑：美股价格、全球情报（新闻、SEC、联邦公报）、可观测量与事件观点结算、单一持仓推荐仓位、估值股数修复、观点辩论模块。

## 三、做对了什么

1. 用户观点先入账原话，再改写为可证伪命题；先找反方证据，不顺着用户找支持。
2. 驳不倒就承认：观点 3 用 Altman、乔布斯的回归反例反驳，再说明它们不是政治性离任，判定立住。
3. 用价格检验市场已经定价了什么：事件窗口按复权总回报、按环节市值加权，看清“分化在客户而不在环节”（华丰 +15% 对鼎通 −16%，曙光 +5% 对工业富联 −18%）。
4. 把“机会”拆成三问：租金归谁、是否已定价、能否投资；漏斗排在最前的低市盈率公司，在用户观点下是周期顶点的便宜，反着读。
5. 结论落到可执行层：仓位上限（损失预算 ÷ 历史最大回撤）、分批条件、失效条件、观察点与对应动作。
6. Agent 自己的判断也入账（长鑫一年跑输沪深300、北方华创一年跑赢沪深300），接受结算检验。
7. 让大师角色挑 Agent 的错：芒格角色指出“现在建 1/3”与“等价格只隐含保守增速”自相矛盾，计划随之修正。

## 四、踩过的坑

1. **未复权价格算年内收益**：截面估值序列的收盘价未复权，送转让胜宏、新易盛的年内跌幅失真；改用 `prices` 的复权总回报。
2. **归因先核对同日基准**：AMD 单日大跌先被归因于自身，核对后是科技股普跌。
3. **时间尺度写错**：观点 3 的命题按 long 入账，检查点落到 2029 年，与用户说的截止日不符；用修订版改为 medium_long（截止 2028-12-31）。
4. **估值股数错误**：境外注册公司的资产负债表“股本”是金额而非股数，中芯市值被算成 268 亿（实际约 9461 亿）；已修复，用“权益 ÷ 每股净资产”复核，并以截面市值交叉核对。
5. **新闻只有标题**：Google 新闻链接是跳转页，正文取不到；事件判定以官方来源为准，媒体报道写“报道称”。
6. **长任务**：117 只的复权价格约 13 分钟；放到后台，同时做行业档案和新闻检索。
7. **辩论没有从一开始就记录**：第一轮的观点与驳斥是事后补录的；以后开题就 `debate --action start`。

1. 第一层与第二层分开：先立住世界观与产业链判断，再逐只检验标的，剪枝理由可追溯。
