# 研究范例

本目录保存真实研究的完整范例：过程、做对的地方、踩过的坑和产物索引，供 Agent 学习“一次研究应该怎样做完”。范例是研究记录，不是可引用的事实来源；引用其中的数据时回到原始条目（账本、情报、报告）并核对截止日。

| 范例 | 范式 | 说明 |
| --- | --- | --- |
| `2026-11-15-美国中期选举与黄仁勋离任.md` | 观点辩论（`.agent/docs/research/playbooks/debate.md`） | 第一次完整走通“消息 → 观点 → 驳斥 → 立住 → 外推剪枝 → 选股 → 计划与验证节点” |

新增范例：研究结束且结论已入账后写；按“为什么是范例、过程、做对了什么、踩过的坑、产物索引、下次怎么做”组织；文件名以研究截止日开头。
