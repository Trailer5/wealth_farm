# 风险预算仓位：外部证据登记

## Moreira–Muir：波动率管理

- 来源：https://doi.org/10.1111/jofi.12513
- 固定引用：`DOI:10.1111/jofi.12513`
- 可借鉴：用前期已实现波动率缩放下一期风险暴露，高波动时减少风险。
- 不采用：论文中的事后缩放常数、美国因子组合、杠杆和收益结论。
- 适用边界：只支持目标波动率作为风险预算起点，不证明在A股上提高收益。

## Cederburg等：实时实施反证

- 来源：https://doi.org/10.1016/j.jfineco.2020.04.015
- 固定引用：`DOI:10.1016/j.jfineco.2020.04.015`
- 反证：波动率管理在实时样本中不一定优于未管理组合，事后系数和结构不稳定会夸大结果。
- 项目约束：缩放公式和参数必须预先固定，使用上一交易日可得数据，并与无择时目标波动基线比较。

## bt：逆波动与调仓实现对照

- 来源：https://github.com/pmorissette/bt/tree/bd5650ad213760907ec38311c5c9468819084196
- 固定引用：`commit:bd5650ad213760907ec38311c5c9468819084196`
- 许可证：MIT
- 审阅路径：`bt/algos.py` 中 `WeighInvVol`、`RunMonthly`、`Rebalance`
- 可借鉴：风险估计、目标权重和实际调仓分层，使用历史窗口计算风险。
- 不采用：数据容器、默认窗口、即时成交和美国市场假设。

## 本项目第一版边界

1. 只做多，不加杠杆。
2. 目标波动率只决定风险仓位上限，不预测收益。
3. 回撤约束和连续择时只减少基础风险仓位。
4. 跟踪误差约束只用于相对收益任务。
5. 参数在验证前冻结，不根据全样本收益调整。
6. 仓位结果必须在实际ETF上做含成本和样本外回测。
