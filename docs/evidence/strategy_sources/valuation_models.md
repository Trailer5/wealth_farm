# 内在价值与隐含预期：方法来源登记

- 方法：`reverse_dcf`、`two_stage_dcf`、`pb_roe`、`normalized_earnings`、`revenue_reverse_dcf`
- 登记日期：`2026-10-27`
- 说明：这些是估值方法，不是交易策略，不经过 `StrategyEvidenceGate`；登记来源、可借鉴部分与不采用部分，供审计。

## Damodaran：折现现金流与相对估值

- 来源：https://pages.stern.nyu.edu/~adamodar/
- 固定引用：Aswath Damodaran, *Investment Valuation*（第 3 版）及其课程讲义。
- 可借鉴：两阶段 FCFF 折现（显式期后接永续增长）、企业价值与股权价值的桥接（加减净负债）、永续增长不应超过长期名义增长、终值占比高时结论对折现率与永续增长敏感。
- 可借鉴：股权价值的 Gordon 形式推出“合理市净率” $P/B = \frac{ROE - g}{r - g}$，用于金融机构。
- 不采用：美国市场的股权风险溢价估计、行业 Beta 表和具体参数。

## Mauboussin 与 Rappaport：预期投资（反向 DCF）

- 来源：https://www.expectationsinvesting.com/
- 固定引用：Michael Mauboussin, Alfred Rappaport, *Expectations Investing*（2021 修订版）。
- 可借鉴：从当前价格反推市场隐含的现金流增长与“价值增长持续期”，再与历史和可实现的经营表现对照，而不是先估一个内在价值再与价格比较。
- 不采用：书中的“价值驱动因素树”全流程与美国公司案例参数。

## 反证与使用边界

1. DCF 结果中终值通常占大部分，折现率或永续增长 1 个百分点的变化就能改变结论，因此只输出情景区间与敏感性表，不输出目标价。
2. 自由现金流对资本开支周期敏感，A 股重资产公司常为负；为负时改用扣非利润口径并标注，不强行求解。
3. 反向 DCF 只说明“价格隐含了什么”，不说明市场错了；隐含增长需与历史增速、行业空间和同行对照后由 Agent 判断。
4. 周期公司用正常化利润（近年利润率中位数）避免把景气顶点或底部外推；正常化本身是假设，须写明所用年份。

## 本项目第一版参数（用户 2026-10-27 确认）

1. 折现率 = 10 年国债收益率 + 股权风险溢价 5%；永续增长 2%；显式期 10 年。
2. 敏感性：折现率 ±1 个百分点 × 永续增长 1%、2%、3%。
3. 参数可在输出中显式调整并记录，不按标的调参。
