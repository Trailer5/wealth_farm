# 当前阶段：全球信息与美股

状态：completed（2026-11-15 起草并当天完成；用户在真实使用期提出，要求补齐美股价格与政策事件类命题的缺口，让 Agent 自主获取全球事件与新闻情报）。

本文把路线图阶段 10 第 3 项“政策文本与新闻的信息入口”提前，并新增“美股价格”能力。起因是真实使用期的研究问题（美国中期选举、英伟达 CEO 离任、对华芯片管制）：大量判断落在美股价格、美国政策与全球新闻上，此前只能由 Agent 临时脚本取数、观点无法入账结算。

## 一、阶段定位

结束时，新对话中的 Agent 能够：

1. 登记美股（股票与 ETF）身份，按需取得复权总回报日线，查看区间收益与回撤；美股观点可按价格入账并由已有结算规则自动结算。
2. 检索全球新闻（英文、中文）、美国证监会公司申报与全文、联邦公报（法规与出口管制规则），结果带发布日期、来源和链接并本地留存；可抓取官方页面正文。
3. 把政策、事件和非结构化数值（如“法案是否通过”“某公司年报毛利率”）登记为可观测量，按证据记录观测值；观点以 `obs:<id>` 指标入账，由已有指标结算规则结算。
4. 例行命令列出需要核实的事件观点，并为每个事件检索新近新闻，供 Agent 核实后记录观测。

涉及系统模块：D1、D2、D3、W3、R5、O1（编号见 `docs/long_term/系统模块总图.md`）。不消除已知偏离，也不新增偏离。

## 三、当前基线（2026-11-15 核实）

1. 身份主数据只解析六位 A 股与场内外基金代码；`market` 只有 `cn_a` 等境内取值。
2. 统一访问的日线按上交所交易日历截断，远程来源全部是境内行情源。
3. 账本价格结算经统一访问取总回报；指标结算支持 `macro:` 与 `fin:`；`record-view` 拒绝未知标的和未知指标。
4. 事件知识（W3）只有 A 股公告标题规则事件；没有新闻、政策文本入口。
5. 本机可用的来源（2026-11-15 实测）：新浪美股日线与复权因子、Nasdaq 行情接口（身份与拆股调整后的日线）、Google 新闻 RSS（英文、中文）、SEC data.sec.gov 与全文检索、www.sec.gov 档案（需要“名称 + 邮箱”形式的 User-Agent）、联邦公报 API。东方财富美股、Yahoo、Stooq、Reuters 直连不可用；GDELT 限流严重。

## 四、设计决策

1. **美股并入统一访问，不另建通道。** 美股以 `market=us` 登记为 `stock` 或 `exchange_fund`（代码即交易代码，如 `NVDA`），日线进入同一张总回报表，复用缓存、覆盖记录、双源交叉核对和账本价格结算。美股资产跳过上交所交易日历；截止日按美东收盘后（UTC 22:00）才视为当天可得。
2. **总回报口径。** 新浪原始日线加新浪前复权因子（拆股乘数与累计分红加数），换算出每天的“除权参考前收盘”，再走既有的前收盘链接法；第二来源是 Nasdaq 接口（只做拆股调整，不含分红，前收盘取上一日收盘），两源差异进入来源冲突提示。货币是美元，不做汇率换算。
3. **情报检索是检索，不是判断。** `intel` 只返回带发布日期、来源和链接的条目并本地留存，供 Agent 引用；不做情绪打分、不做自动摘要。时间窗口按发布日期过滤，检索截止日之后的条目不返回。
4. **事件观点用“可观测量”承载，不改核心契约。** 新增 `obs:<id>` 指标命名空间：可观测量定义（标题、类型 event/value、单位、判定标准、新闻检索词）与观测记录（值、所属日期、可得日期、证据）分开保存，观测只追加。观点照旧用 `metric_observation` 结算：
   - 事件类取值 0/1（未发生/已发生），用 `max_level` 判定“截止前是否发生”；
   - 数值类按期记录，用 `level` 或 `level_at:<期末日>` 判定；
   - 判定只用检查点前可得（证据发布日期不晚于检查点）的观测；
   - 事件类观点在到期前尚未越线时不判定（记为不可结算并注明“到期再判定”），越线即提前判定；到期仍无新观测时记为数据不足，等待 Agent 核实后记录。
   这样观点、计划和可结算动作的核心契约不变，账本只增加一个指标来源。
5. **证据纪律。** 每条观测必须带证据（`intel:<条目>` 或带日期的链接），证据日期不得晚于记录日；观测的“可得日期”取证据发布日期，防止事后补记被当作当时已知。结算备注标明“Agent 依据证据记录的观测，非确定性数据源”，决策复盘可按此区分。
6. **例行命令。** `routine` 新增“事件核实”一步：列出到期待判定的 `obs:` 观点，并按每个可观测量的检索词拉取上次观测以来的新闻，作为 `next_actions` 交给 Agent 核实。

## 六、明确不处理

1. 美股持仓与组合：`record-holding` 仍只接受境内代码；组合诊断、配置与计划不含美股，也不做汇率换算（下一步候选）。
2. 美股财务报表的确定性指标（`fin:`）：本阶段由 `obs:` 数值类观测承接（证据为 SEC 申报）；SEC XBRL 的确定性接入留待后续。
3. 美国宏观序列、港股、全球指数。
4. 新闻情绪、自动摘要、事件自动抽取和定时监控。

## 七、结算方式

- 美股价格观点：`price_relative`，与 A 股相同（复权总回报，按检查点）。
- 事件与非结构化数值观点：`metric_observation` + `obs:<id>`，按 Agent 依据证据记录的观测结算。
