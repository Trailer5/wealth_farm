# Research 任务策略手册

## 用途

Agent 在进入查询前先判断研究任务类型。不同任务使用不同假设、证据、时间尺度、反证和停止条件，不把所有问题套进同一份单标的清单。

确定性身份、数据、指标、图表、规则和产物仍必须调用 `src/research_orchestration/` 公共入口。本文件只规定 Agent 如何组织探索和判断。

## 共同入口判断

每项研究先确认：

1. 对象：单标的、多个标的、指数、行业、市场或外部事件。
2. 问题：理解、比较、择时、投机、投资、周期、发现、复核。
3. 时间尺度：短期、中短期、中长期或长期。
4. 截止时间：信息知识截止与收益观察截止是否不同。
5. 决策：用户要理解现象、寻找候选、调整仓位还是复核报告。
6. 证据门槛：哪些问题未回答就必须停止。

## 一、事实理解型

适用：公司做什么、事件发生了什么、基金跟踪什么、数据为何变化。

策略：

1. 先解决身份和口径，不先提出买卖判断。
2. 区分官方事实、第三方汇总和项目派生值。
3. 对冲突来源按发布时间、定义和原文复核。
4. 只解释当前问题需要的因果链，不扩展成完整投资报告。

停止条件：核心身份、时间和定义已确认；剩余不确定性不改变答案。

## 二、横向比较型

适用：同行、ETF工具、行业、指数或方案比较。

策略：

1. 先解释为什么可比，再比较指标。
2. 统一币种、会计期、收益口径、费用、基准和观察窗口。
3. 保存排除对象及原因，不只展示优胜者。
4. 不跨不同底层风险暴露机械排名。

停止条件：比较口径一致，主要差异能解释，排除偏差已检查。

## 三、中长期投资型

适用：商业质量、盈利持续性、估值和长期配置。

策略：

1. 建立商业模式、竞争优势、资本配置和治理假设。
2. 连接收入、利润、现金流和资产负债表，不只看估值倍数。
3. 使用历史、同行和周期位置解释当前定价。
4. 建立最强反方、情景和失效条件。
5. 最终仓位必须来自投资任务和组合约束。

停止条件：价值来源、价格隐含预期、主要风险和失效条件均已闭环。

## 四、短期择时型

适用：趋势、市场状态、执行窗口和仓位调整。

策略：

1. 使用与短期问题一致的日线或更高频数据。
2. 明确事件时间、信号时间、下一可交易时间和T+1。
3. 区分市场价格、NAV、总收益和基准。
4. 检查涨跌停、停牌、滑点、容量和拥挤度。
5. 短期命中不外推为长期价值判断。

停止条件：信号可交易、风险预算可执行、反向条件可监控。

## 五、事件投机型

适用：财报、政策、并购、诉讼、产品、外部重大事件。

策略：

1. 冻结首次公开时间和知识截止，不使用事后信息解释事前交易。
2. 列出直接受益、替代交易、预期差和利好兑现四种路径。
3. 检查事件是否已经定价，以及是否存在更直接的同期催化。
4. 分别研究事件反应和事件后反转，不把二者混成一个信号。
5. 没有事件时点或交易日历时停止因果归因。

停止条件：事件、传导渠道、替代解释和可交易窗口均已确认。

## 六、发现探索型

适用：从市场、行业、事件或异常行为中寻找研究候选。

策略：

1. 调用发现编排器，接收全体候选、淘汰和数据不足结果。
2. 先评价发现机制和覆盖偏差，再选择深度研究对象。
3. 候选必须重新进入单标的研究，不直接进入推荐。
4. 已知案例只能验证流程；正式验证先冻结 manifest。
5. 探索可以产生新假设，但不能用 prompt 填补底层数据。

停止条件：候选产生原因可解释，主要误报来源已检查，研究任务草稿可执行。

## 七、市场与指数型

适用：市场状态、指数估值、行业贡献和资产配置。

策略：

1. 区分价格指数、全收益指数和实际可交易ETF。
2. 多口径估值分别保存，不挑选最支持结论的口径。
3. 当前行业截面不包装成历史指数归因。
4. 宏观数据严格遵守发布日期；当前描述代理不进入历史回测。
5. 指数判断最终落到实际工具、费用、跟踪和组合风险。

停止条件：市场判断、实际工具和风险约束能够一致解释。

## 八、报告复核型

适用：机构质量评估、整改复核和已有结论审查。

策略：

1. 从结论反查数据、方法、时点、基准和执行条件。
2. 区分已修复、部分修复、外部阻塞和明确取消。
3. 不因测试通过就上调投资证据等级。
4. 保留整改前结论，避免覆盖历史审计。

停止条件：每个核心结论都能对应证据或明确缺口。

## 市场共识与名称注意力专项

重大事件造成名称炒作时，Agent 不应假设存在大量真正误认的投资者，也不应直接声称统一主力或违法操纵。

更合理的机制链：

1. **事件显著性**：影响足够大的事件成为所有参与者共同看到的公共信号。
2. **叙事简单性**：名称、谐音或字面联想能够一句话传播。
3. **协调焦点**：证券成为无需显式串谋即可共同选择的“谢林点”。
4. **边际价格弹性**：小市值、低流通或卖盘撤退使少量资金可以显著改变边际价格。
5. **预期他人参与**：参与者可以知道关系荒谬，但预期后续打板、动量或跟随资金继续买入。
6. **传播反馈**：涨停和异动本身变成新闻，进一步强化叙事。
7. **套利约束**：涨跌停、T+1、做空困难和借券限制延长偏离。
8. **市场风险偏好**：流动性和投机偏好影响共识是否能够扩散，但“资金无处可去”不是必要条件。
9. **跨境距离**：全球事件与中国上市公司之间缺少直接传导，反而为象征性联想留下想象空间。
10. **中国关注度**：事件必须被中国投资者广泛关注；单纯海外重要但国内无感的事件不能形成A股协调点。

进入名称扫描前先过“注意力冲击事件”门禁，六项必须同时成立：

1. 有单一、明确的首次公开时间；
2. 事件突发，或正式宣布了决定性结果；
3. 全球普通公众广泛关注，而不只是专业领域重要；
4. 中国普通投资者同样高度关注；
5. 正负方向或情绪冲击无需专业分析即可理解；
6. 事件有唯一人物、产品、结果或行动名称，不能只是“乌克兰”“非洲”“金砖”等长期背景词。

Agent 必须区分：

1. `mistaken_identity`：真实标的混淆或错误交易。
2. `consensus_speculation`：参与者理解无关，但交易后续共识。
3. `alternative_theme`：存在机器人、低空经济等更直接题材。
4. `real_economic_relation`：真实产业、股权、客户或供应链传导。
5. `mixed_catalyst_overlay`：IPO、财报等直接催化存在，但名称叙事可能解释超出同类基线的增量反应。

名称通道必须区分汉字、谐音、拼音首字母、英文缩写、ticker 混淆和品牌名称。三位英文缩写只有在事件短语显式登记且具有来源时才允许匹配，不能扫描后按涨幅反向挑缩写。

对于品牌或产品案例，按“搜索注意力 → 情绪 → 购买意向 → 实际销售 → 证券价格”分层验证。低层注意力成立不代表高层经济影响成立；例如品牌口碑下降但实际销售没有下降时，只能结论为注意力外溢。

使用步骤：

1. 先冻结事件来源、时间、短语和优先级。
2. 调用 `EventNameDiscoveryOrchestrationPipeline`。
3. 准备经济关系、替代催化和共识形成三组证据。
4. 共识证据至少覆盖全球影响、中国关注度、叙事距离、事件显著性、叙事简单性和协调焦点；价格弹性、传播、套利约束和风险偏好用于判断共识强度。
5. 若存在IPO等直接催化，必须建立同类基线；只能把超出基线的部分列为名称叙事增量，证据不足时标为混合归因。
6. 使用显式交易日历计算异常价格、成交和反转。
7. 候选进入探索会话，继续验证共识、替代解释和执行约束。
8. 正向涨停默认作为风险观察；负向误杀才可研究做多修复。

预测能力验证必须使用 `EventNameDiscoveryMode.PREDICTIVE`，该模式拒绝任何事件日或后续行情输入。候选列表持久化后才能调用行情计算。没有事前候选时应直接报告覆盖率为零，不能用被门禁拒绝的弱匹配事后收益证明策略有效。

国内官方大事不适合作为该机制的主要事件母集：距离过近、真实政策传导过强、想象空间有限。严格验证应使用“全球有重大影响且中国高度关注”的跨境事件，并以中国媒体的国际年度新闻或预注册全球事件源证明国内关注度。后续若研究预测能力，优先使用实时影子运行，或预先取得带时间戳的搜索趋势、新闻转载和社交叙事数据；不得在同一历史样本上继续创造别名和调阈值。

禁止：

1. 用“散户愚蠢”“主力操纵”替代证据。
2. 把市值上涨理解为等额资金净流入。
3. 看到涨停后反向编造谐音短语。
4. 忽略同期公司公告、行业主题和真实关系。
5. 把回顾性案例写成样本外收益证明。
