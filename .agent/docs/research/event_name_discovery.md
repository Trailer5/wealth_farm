# 事件名称注意力发现

## 适用范围

仅当用户研究重大外部事件、证券名称/谐音错配或经济无关标的异常时读取。普通单标的研究和一般事件投资不加载本专题。

重大事件造成名称炒作时，不假设存在大量真正误认的投资者，也不直接声称统一主力或违法操纵。

## 机制假设

1. 事件成为参与者共同看到的显著公共信号。
2. 名称、谐音或字面联想可以低成本传播。
3. 证券成为无需显式串谋即可共同选择的协调焦点。
4. 小市值、低流通或卖盘撤退提高边际价格弹性。
5. 参与者即使知道经济关系薄弱，也可能预期后续动量资金参与。
6. 涨停和异动本身形成传播反馈。
7. 涨跌停、T+1、做空和借券约束延长偏离。
8. 市场风险偏好影响扩散强度，但“资金无处可去”不是必要条件。
9. 全球事件与中国上市公司之间的跨境距离可能放大象征性联想。
10. 事件必须被中国普通投资者广泛关注，单纯海外专业重要性不足。

## 注意力冲击事件门禁

进入名称扫描前必须同时满足：

1. 有单一、明确的首次公开时间；
2. 事件突发，或正式宣布决定性结果；
3. 全球普通公众广泛关注，而不只是专业领域重要；
4. 中国普通投资者同样高度关注；
5. 正负方向或情绪冲击无需专业分析即可理解；
6. 有唯一人物、产品、结果或行动名称，不是长期国家、地区或议题背景词。

国内政策和产业事件通常真实传导过强，不适合作为名称外溢主要母集。严格验证优先使用全球有重大影响、中国高关注且跨境距离足够的事件。

## 归因分类

- `mistaken_identity`：真实标的混淆或错误交易。
- `consensus_speculation`：参与者理解经济无关，但交易后续共识。
- `alternative_theme`：存在更直接的行业或主题解释。
- `real_economic_relation`：存在真实产业、股权、客户或供应链传导。
- `mixed_catalyst_overlay`：IPO、财报等直接催化与名称叙事并存。

名称通道必须区分汉字、谐音、拼音首字母、英文缩写、ticker 混淆和品牌名称。三位英文缩写只有在事件短语事前登记且有来源时才允许匹配，不能观察涨幅后反向挑选。

品牌或产品案例按“搜索注意力 → 情绪 → 购买意向 → 实际销售 → 证券价格”分层验证；低层注意力不代表高层经济影响。

## 正式流程

1. 冻结事件来源、首次公开时间、时区、方向、短语和优先级。
2. 调用 `EventNameDiscoveryOrchestrationPipeline` 或 `run-event-name-discovery`，不得手工遍历全市场。
3. 准备主营、股权、商业联系和公告联系四类经济关系证据。
4. 准备公司公告、行业主题、公司行动和市场叙事四类替代催化证据。
5. 评估全球影响、中国关注、叙事距离、事件显著性、叙事简单性和协调焦点；价格弹性、传播、套利约束和风险偏好用于判断强度。
6. 直接催化并存时建立同类基线，只把超出基线且有证据的部分列为名称叙事增量。
7. 使用显式交易日历计算异常价格、成交和反转；盘中事件只有日线时不做当日因果归因。
8. 候选进入探索会话，继续验证共识、替代解释和执行约束。
9. 正向涨停默认作为风险或反转观察；负向误杀才可进入中短期做多研究。

候选必须同时保留名称解释、关系证据、替代催化、共识形成、异常行情和反证。

## 预测验证

已知历史案例只能验证流程，不能证明策略收益。正式预测必须：

- 使用 `EventNameDiscoveryMode.PREDICTIVE`；
- 在查看事件日及后续行情前持久化候选 manifest；
- 冻结事件 ID、短语优先级、匹配器版本、规则和训练/留出归属；
- 没有事前候选时报告覆盖率为零，不用门禁拒绝的弱匹配事后证明有效。

后续预测研究优先实时影子运行，或使用带时间戳的搜索趋势、新闻转载和社交叙事数据；不得在同一历史样本上持续创造别名和调阈值。

## 禁止事项

1. 用“散户愚蠢”或“主力操纵”代替证据。
2. 把市值上涨理解为等额资金净流入。
3. 看到涨停后反向编造名称或谐音。
4. 忽略同期公司公告、行业主题和真实经济关系。
5. 把回顾性案例写成样本外收益证明。
6. 手工刷新 universe、循环 batch 或直接加载内部 SQLite。
